# 设计文档：营收兑现追踪体系（chain-alpha-delivery-tracking）

- 日期：2026-06-18
- 作者：InvestmentFlow
- 状态：已通过设计评审，待写实现计划
- 目标：为 chain-alpha `待验证 / 观察池` 标的（如绿的谐波 688017）提供一套**前瞻性、双向对称、可证伪**的"营收兑现"判断体系，沉淀为可复用 skill，并接入 chain-alpha 档位升降。

## 0. 问题与定位

现有跟踪体系（professional-investment-analyst 的"跟踪指标 Dashboard"、chain-alpha-verification 的"跟踪指标 / 升档触发"）以**滞后财务指标 + current 值**为主。对 `待验证` 标的不适用：这类标的的成长（如人形机器人收入）当前在财报里几乎为 0，等它显现在财报上时股价往往已完成 re-rating。

**核心命题：** 营收兑现 = 现实沿一条验证链往前推进的进度，对比估值已经 price-in 的位置。
- 升档（拓仓）：现实推进速度 > 预期、且估值未吃满。
- 降档（证伪）：某一环卡住 / 指引下修。

**定位：** chain-alpha-verification 的下游模块。输入为 verification 产出的 `待验证`（及在监控中的 `通过/金池子`）标的，输出兑现度结论 + 升/降档建议，回灌 chain-alpha 档位与仓位。

## 1. 架构总览

体系 = **验证链阶段闸门（骨架）** + **三个判定引擎（增速/归因/动态估值）** + **升降档与档位映射（回灌 chain-alpha）**。

- 阶段闸门：诚实判断"兑现到了哪一级"，防跳级，双向对称。
- 三引擎：在 L4/L5 层做硬兑现确认与防坑。
- 预期差对账嵌在引擎 A/C；归因闸门是 L4 的子门；动态估值是引擎 C。

设计取舍记录（已评审）：
- 选 A（阶段闸门）为骨架，而非纯 B（单一 0-100 评分）——评分会把"订单热度"和"入表事实"混在一起、掩盖跳级，不如闸门诚实。B 评分降级为**可选的观察池排序辅助层**。
- 预期差（C 思路）嵌入而非独立——独立模型依赖量化指引（很多 A 股不给）、早期无 gap 可对。

## 2. 验证链 5 级阶段闸门

规则：**逐级点灯、不可跳级；估值只能按"已点亮的最高级"给；低级热、高级暗 = 纯预期，不算兑现。**

| 级别 | 闸门 | 点亮标准（可证伪硬证据） | 不算点亮（伪信号） | 性质/频率 |
|---|---|---|---|---|
| L1 | 订单/定点 | 进客户合格供应商名录(AVL)、定点函(SOP nomination)、中标/框架协议、批量订单公告 | 送样、接洽、战略合作 MOU、媒体传闻 | 领先·事件驱动 |
| L2 | 产能/供应链 | 该业务产线投产/达产、在建转固、稼动率提升、送样→小批量→量产阶段切换（公告或产业链调研验证） | "规划产能""拟投资""预计量产" | 领先·季度 |
| L3 | 下游放量 | 所绑定整机厂（Optimus/宇树/Figure…）实际出货/排产上量，带动本供应商出货上台阶 | 整机厂发布会、路线图、目标产量口号 | 半领先·季度 |
| L4 | 入表（分水岭） | 目标业务分部收入显性出现 **且** 增速达标（引擎A）**且** 归因达标（引擎B）**且** 占比连续 ≥2 季上升 | 总收入涨但拆不出来 / 靠理财补贴撑 / 占比不升 | 滞后·硬·季度 |
| L5 | 盈利兑现 | 目标业务毛利率企稳或改善、净利与经营性现金流跟上、应收/存货质量健康（非靠放账期铺货堆收入） | 增收不增利、利润靠非经常、应收激增 | 最滞后·硬·季度 |

## 3. 三个判定引擎

### 引擎 A — 增速判定
- 指标：目标业务收入 YoY、净利 YoY（辅以 QoQ 看拐点）、连续达标季数。
- "预期"锚三条：**① 估值隐含增速（主锚）**、② 指引隐含、③ 同环节可比中位数。
- 输出：达标（≥隐含）/ 相当 / miss；连续 miss 计入降档。

### 引擎 B — 归因判定（质 / 量 / 势，阈值可调、不写死）
- **质**：增量是否来自经常性目标业务？剔除理财收益、政府补贴、汇兑、并表、会计口径变更等一次性。
- **量**：目标业务增量 ÷ 总增量 ≥ 可配阈值（默认判"是否主导"，不固定为某个数字；50% 仅为举例口径，按标的/场景设定）。
- **势**：目标业务收入占比是否连续 ≥2 季上升。
- 输出：达标 / 存疑 / 不达标。不达标 = "账面兑现非业务兑现"，L4 不点亮。

### 引擎 C — 动态估值判定（PE/PS 双轨 + 历史分位锚 + 重估开关 + SOTP）

**双轨（不只看 PE）：** PS/EV·Sales 与 PE/EV·EBIT 并看。早期 E 太小或失真（净利大幅波动、靠理财）时 PE 无意义，须用 PS 盯收入兑现。

| 轨 | 主看阶段 | 对应链 | 含义 |
|---|---|---|---|
| PS / EV·Sales | 早期、薄利、放量期 | L4 收入兑现 | 收入兑现进度与 price-in 程度 |
| PE / EV·EBIT | 利润成熟期 | L5 盈利兑现 | 利润是否跟上 |

桥接恒等式 `PS ÷ 净利率 = PE`：
- forward PS 压缩（收入兑现）但 forward PE 不降 → **增收不增利**，卡 L4 上不去 L5 → 降档/透支钩子。
- 两轨同步压缩 → 收入+利润双兑现 → 升档强信号。

**① 历史分位锚（不看绝对值）：** 用本期增速外推 forward PS/PE，再比对**该股自身历史 PS/PE 分位带**。历史均值 100x，则 forward 110x 也可能合理；看落在自身历史什么分位，不看绝对高低。

**② 重估开关（业务变了换眼光，但重估必须被验证链背书）：**
- 触发：业务发生 regime change（老业务 → 新成长曲线），历史 PE 失效（类比：特斯拉不再按车企、美光脱离存储周期）。
- 准许换"新眼光"取决于验证链：
  - L3/L4 已亮（新业务真放量入表）→ **重估成立**，切到新 comp / 新框架 / SOTP 分部估值。
  - L1-L2 热但 L4 暗 → **重估未被兑现背书 = 纯叙事拔估值（反身性透支）**，不给新带，反记透支风险（降档钩子）。借 reflexivity skill 视角。

**③ SOTP 工具：** 转型期公司默认可拆分部估值（老业务×老倍数 + 新增量×成长倍数），避免单一倍数一刀切。

- 输出：forward 估值 进入合理带 / 匹配 / 透支 / 重估后重定价合理。

## 4. 升降档规则与 chain-alpha 档位映射（双向对称）

每个跟踪周期（L4/L5 与引擎按季度；L1-L3 事件驱动）评估"当前最高点亮级别 + 三引擎读数"，给出动作：

```
升档（待验证→通过，通过→金池子）
  需同时：灯进 L4  ∧  A 达标  ∧  B 达标  ∧  C(进合理带 或 重估被验证链背书)
  注：L4 点亮已内含 A 达标 + B 达标 + 占比连升，故升档相对"L4 点亮"的增量要求实为 C（估值进合理带或重估被背书）；此处显式并列以防误读。
  → 触发 chain-alpha 仓位（"通过"× 0.5；弹性标的再 × 0.5）

降档（通过→待验证/剔除，待验证→剔除）
  触发其一：灯熄（丢单/指引下修） ∨ A 连续 miss ∨ B 恶化（靠非经常性撑） ∨ C 因下修/叙事透支重新扩张

维持（待验证）
  其余：列明"还差哪一项可升档"（如"灯到 L3、A 达标，但 L4 未入表 + C 仍透支"）
```

**回灌 chain-alpha：** 更新对应 verification 验证卡的档位 + 仓位上限，产出"本期 vs 上期"变更 delta 与触发项；维持 chain-alpha 既有回撤推断与风险预算法仓位公式不变。

**可选 B 评分：** 输出 0-100 兑现度分仅用于观察池内排序，不得凌驾于阶段闸门之上（不能用高分救回未点亮 L4 的标的）。

## 5. 输出模板（兑现追踪卡）

固定中文 Markdown，字段：
1. 标的 / Ticker / 所属环节 / 本期日期 / 上次复盘日期
2. 验证链灯带：L1–L5 当前点亮状态（亮/部分/暗）+ 本期相对上期的灯位变化
3. 引擎 A：目标业务收入与净利 YoY、三锚对比（估值隐含/指引/可比中位数）、连续达标季数
4. 引擎 B：质（一次性剔除明细）/ 量（目标业务增量占比）/ 势（占比轨迹），归因结论
5. 引擎 C：forward PS、forward PE 双轨 vs 各自历史分位带；重估状态（无/候选/成立）；SOTP（如适用）
6. 预期差对账：上期指引 vs 本期实际
7. 本期结论：升 / 降 / 维持 + 触发的具体项
8. 回灌 chain-alpha：新档位、新仓位上限、delta
9. 反证条件更新 + 下次复盘时间
10. 数据来源（区分 事实 / 推断 / 假设）

## 6. 数据源与口径

- 优先级：公司公告/财报分部/电话会/IR（硬，L4/L5 与引擎 A/B）＞ 交易所披露 ＞ 行业数据/产业链调研（L1-L3 领先信号）＞ market-data-router（PS/PE、历史分位、价格回撤）。
- PS/PE 历史分位、价格回撤经 market-data-router 取数；降级取数时降低置信度并标注。
- 各市场口径沿用 chain-alpha-verification：A 股比 A 股、日股比日股；历史分位用该股本地市场数据。
- 严格区分 事实 / 推断 / 假设；关键数字标来源与日期；不得编造。

## 8. 验收标准

- 对一个真实 `待验证` 标的（绿的谐波 688017）跑通：产出兑现追踪卡，给出当前最高点亮级别、三引擎读数、升/降/维持结论与触发项、回灌后的档位/仓位。
- 阶段闸门不可跳级、不可被 B 评分绕过（有反例校验）。
- 升档与降档触发**双向对称**可用。
- PE/PS 双轨、历史分位锚、重估开关（含"未被验证链背书则记透支"）在卡中均有体现。
- 全程区分事实/推断/假设；非美股（A/港/日/台）不被排除，按本地口径处理。

## 9. 暂不纳入（YAGNI）

- 自动定时跑批/盯盘（先做手动/按需触发）。
- 自动下单或仓位执行（输出是研究与跟踪优先级，不是交易指令）。
- 跨标的组合层优化（本 skill 聚焦单标的兑现判断）。
