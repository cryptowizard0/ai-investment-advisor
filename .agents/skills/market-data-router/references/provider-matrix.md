# 数据源路由矩阵（美股优先）

本矩阵只定义**路由优先级**，不替代数据源官方文档。
若请求失败或覆盖缺失，按降级策略回退（见 `fallback-policy.md`）。

| 数据类型 | 主源 | 备源 | 备注 |

| L1 订单簿 | AllTick | 无 | 若主源缺失，标记不可用 |
| 期权 | Polygon | 无 | 只对 US 期权有效 |

## 关键路由规则（摘要）

- **期权/暗池**：只走 Polygon（US-only）
- **bars**：AllTick 为主，Yahoo 仅作兜底（US/HK/CN/FUT）；非 5m 允许 5m 聚合
- **覆盖缺失**：不伪造数据，直接标记不可用
- **市场降级**：HK/CN/FUT 只保证 5m bars
