## 示例 1: TSLA 温和吸筹案例 (2024年1月)

### 原始数据

**价格数据:**
- 分析日期: 2024-01-25
- 当前价格: $225.50
- 20日价格区间: $212.00 ~ $248.00
- 20日均线: $228.00
- VWAP: $220.30

**成交量数据:**
- 1/18 (弹簧日): 成交量 1.85亿，20日均量 1.02亿 (181%)
- 当日开盘: $215.00，最低: $212.00，最高: $219.50，收盘: $218.00
- 1/19-1/24: 平均成交量 0.48亿 (47%均量)，平均振幅 1.8%

**技术指标:**
- OBV: 1/18低点时 OBV = 2.45亿，前低(1/10)时 OBV = 2.37亿 (+3.4%)
- CMF: 从 1/15 的 -0.31 回升至 1/25 的 -0.12
- RSI: 价格 $212 时 RSI = 28，前低 $215 时 RSI = 22 (+6点)

**盘口数据:**
- 暗池成交占比: 41.2%
- 暗池成交价相对公开市场溢价: 0.42%
- 盘后大宗交易: 无显著记录

**期权数据:**
- Call 成交量: 3.2倍20日均量 (320%)
- 大单成交占比: 34%
- 主要行权价: $240 (OTM, 虚值6.4%)
- Put/Call 比: 0.62 (5日平均)
- Call IV: 45.2%，Put IV: 41.1%，Skew: +4.1%

---

### 评分卡计算过程

#### Dimension 1: VSA 量价分析

**信号1: 弹簧模式 (Spring)**
判定条件检查:
- [x] ① 价格短暂跌破关键支撑位: $212 < $218支撑 (跌幅2.8%)
- [x] ② 当日收于支撑位上方: $218 接近支撑位
- [x] ③ 成交量放大: 181% > 120%均量
- [x] ④ 下影线长度 > 实体2倍: 下影线$6，实体$3，比值2.0

满足: 4/4 条件 → **+10分**

**信号2: 量缩整理 (Test)**
判定条件检查:
- [x] ① 连续3日+窄幅整理: 1/19-1/24 (6日)
- [x] ② 成交量 <50%均量: 47% < 50%
- [x] ③ 发生在支撑位附近: $220 接近 $218支撑
- [x] ④ K线实体逐渐缩小: 是

满足: 4/4 条件 → **+7分**

**VSA维度小计: +10 + 7 = +17分** (上限25分，取+17)

---

#### Dimension 2: 技术指标背离

**信号1: OBV强底背离**
判定条件检查:
- [x] ① 价格创20日新低: $212 是20日最低
- [x] ② OBV高于前低 >3%: +3.4% (>3%)
- [x] ③ 持续至少3个价格低点: $240→$228→$215→$212 (4个低点)
- [x] ④ OBV突破下降趋势线: 是

满足: 4/4 条件 → **+10分**

**信号2: CMF温和买入**
判定条件:
- CMF从 -0.31 回升至 -0.12 (负值区间向0靠近)

满足 → **+5分**

**信号3: VWAP温和支撑**
判定条件检查:
- [x] ① 价格 > VWAP: $225.50 > $220.30
- [ ] ② 近5日有≥2次回调至VWAP反弹: 仅1次 (1/22)
- [x] ③ 当前价格在VWAP上方 >2%: +2.4%

满足: 2/3 条件 → **+4分**

**信号4: RSI底背离**
判定条件:
- 价格新低，RSI抬高6点 (>5点)

满足 → **+3分**

**技术维度小计: +10 + 5 + 4 + 3 = +22分** (上限25分，取+22)

---

#### Dimension 3: 盘口微观结构

**信号1: 暗池吸筹**
判定条件检查:
- [x] ① 暗池成交占比 >40%: 41.2% > 40%
- [x] ② 暗池成交价溢价 >0.3%: 0.42% > 0.3%
- [x] ③ 出现在价格低位: $225 处于20日区间下30%位置

满足: 3/3 条件 → **+10分**

**信号2: 大宗交易**
- 无显著大宗交易记录 → **0分**

**信号3: 冰山订单**
- 未观察到典型冰山订单模式 → **0分**

**盘口维度小计: +10 + 0 + 0 = +10分**

---

#### Dimension 4: 期权链异动

**信号1: Call激增(吸筹)**
判定条件检查:
- [x] ① Call成交量 >300%均量: 320% > 300%
- [x] ② 大单成交占比: 34% > 30%
- [x] ③ 主要集中在OTM Call (5-15%虚值): $240 Call 虚值6.4%
- [x] ④ 出现在价格低位: 是

满足: 4/4 条件 → **+10分**

**信号2: P/C比温和乐观**
- P/C = 0.62，落在 0.5-0.7 区间 → **+2分**

**信号3: IV Skew看涨**
- Call IV > Put IV 4.1% (>3%) → **+4分**

**期权维度小计: +10 + 2 + 4 = +16分**

---

### 总分计算

```
总分 = VSA(+17) + 技术(+22) + 盘口(+10) + 期权(+16) = +65分
```

### 分类判定

**区间检查:**
- 总分 +65 落在 +50~+74 区间
- 必要条件: VSA ≥ +5 (+17 ✓) 或 技术 ≥ +5 (+19 ✓)

**判定结果:** 🟡 **温和吸筹**

---

### 置信度计算

**证据统计:**
- 强证据 (>8分): 弹簧(10) + OBV背离(10) + 暗池(10) + Call激增(10) = **4个**
- 中证据 (=8分): **0个**
- 弱证据 (<8分): 量缩(7) + CMF(5) + VWAP(4) + RSI(3) + P/C(2) + IV Skew(4) = **6个**

**加成计算:**
- 基础分: 50%
- 证据加成: 4强 + 0中 + 6弱 → **+20%** (参考scoring-system.md加成表)
- 强度加成: 最大维度22分 → **+10%**
- 完整性加成: 100%数据完整 → **+5%**
- 原始置信度: 50 + 20 + 10 + 5 = **85%**
- 调整系数 (|65|分 ≥ 60): **0.95**

**最终置信度: 85% × 0.95 = 80.75% → 81%**

---

### 最终结论

| 项目 | 结果 |
|------|------|
| **分类** | 🟡 温和吸筹 |
| **总分** | +65/100 |
| **置信度** | 81% (高) |
| **关键证据** | 弹簧模式、OBV强底背离、暗池吸筹、Call激增 |
| **机构成本区** | $210 - $225 |
| **当前位置** | 处于成本区上部 (约75%) |
| **风险价位** | 跌破 $212 则吸筹信号失效 |

## 示例 2: AAPL 疯狂出货案例 (2024年8月)

### 原始数据

**价格数据:**
- 分析日期: 2024-08-15
- 当前价格: $218.50
- 近期高点: $237.50 (8/1)
- 20日高点: $237.50
- VWAP: $228.00

**成交量数据:**
- 8/1 (高点日): 成交量 1.2亿，20日均量 0.68亿 (176%)
- 当日开盘: $232.00，最高: $237.50，最低: $229.00，收盘: $230.50
- 8/2-8/15: 价格持续下跌，成交量维持在 0.9-1.1亿

**技术指标:**
- OBV: 8/1高点时 OBV = 3.12亿，前高(7/25)时 OBV = 3.28亿 (-4.9%)
- CMF: 从 7/25 的 +0.28 下降至 8/15 的 -0.18
- RSI: 价格 $237.5 时 RSI = 72，前高时 RSI = 78 (-6点)

**盘口数据:**
- 暗池成交占比: 43.5%
- 暗池成交价相对公开市场折价: 0.55%
- 盘后大宗交易: 8/5 盘后成交 1200万股 (约 $2700万)

**期权数据:**
- Put 成交量: 3.2倍20日均量
- 主要行权价: $210 (OTM Put)
- Put/Call 比: 1.45 (5日平均)
- Put IV: 38.5%，Call IV: 33.2%，Skew: -5.3%

---

### 评分卡计算过程 (简化版)

#### VSA 维度: -25分
- 放量滞涨 (8/1): 成交量176% + 收长上影 + 涨幅回落 → **-10分**
- 上抛失败: 假突破 $235 阻力 + 次日低开 → **-8分**
- 量增下跌: 多日在高量下下跌 → **-7分**
- **小计: -25分** (达到下限)

#### 技术维度: -24分
- OBV强顶背离: 价格新高 + OBV降低4.9% → **-10分**
- CMF强势卖出: 从+0.28降至-0.18 (<-0.25) → **-8分**
- VWAP强势阻力: 价格<VWAP，多次反弹遇阻 → **-7分**
- RSI顶背离: RSI降低6点 → **-3分**
- **小计: -28 → -25分** (达到下限)

#### 盘口维度: -18分
- 暗池派发: 占比43.5% + 折价0.55% → **-10分**
- 大宗卖出: 盘后1200万股，成交价≤收盘 → **-8分**
- **小计: -18分**

#### 期权维度: -19分
- Put激增做空: 成交量320% + 价格高位 → **-10分**
- P/C极度悲观: 1.45 > 1.3 → **-5分**
- IV Skew看跌: -5.3% → **-4分**
- **小计: -19分**

### 总分与结论

```
总分 = -25 + (-25) + (-18) + (-19) = -87分
```

**分类判定:**
- 总分 -87 落在 -100~-75 区间
- 必要条件: (VSA ≤ -10 且 技术 ≤ -5) 或 (VSA ≤ -5 且 技术 ≤ -10)（-25 ✓）

**结论:** 🔴 **疯狂出货**

**置信度:**
- 强证据(>8): 4个
- 中证据(=8): 3个
- 弱证据(<8): 5个
- 证据加成: 4强 + 3中 + 5弱 → +22%
- 强度: 25分 → +10%
- 完整度: 100% → +5%
- 原始: 50+22+10+5 = 87%
- 调整系数 (|87|≥80): 1.0
- **最终: 87%**


## 常见错误与纠正

### 错误 1: 阈值理解偏差
**错误示例:**
- "成交量放大" (模糊)
- 模型A理解: >120%  模型B理解: >150%

**纠正:**
- 必须明确: "成交量 1.8倍20日均量 (180%)"
- 引用具体阈值: ">150%均量" (scoring-system.md VSA标准)

### 错误 2: 证据与得分不匹配
**错误示例:**
- 声称"OBV底背离"，但OBV差距仅1%
- 评分卡要求: >3%

**纠正:**
- 检查原始数据: "OBV抬高 4.2%"
- 明确满足条件: ">3%差距 ✓"

### 错误 3: 分类边界模糊
**错误示例:**
- 总分74分，模型A分类"温和吸筹"
- 总分75分，模型B分类"强力吸筹"

**纠正:**
- 严格按区间: 74分=温和吸筹，75分=强力吸筹
- 检查必要条件: 强力吸筹需VSA≥10 & 技术≥10

### 错误 4: 置信度主观估算
**错误示例:**
- "置信度约80%" (无计算过程)

**纠正:**
- 展示计算步骤:
```
证据: 3强 + 4弱 → +15%
强度: 18分 → +5%
完整: 75% → +3%
原始: 50+15+5+3 = 73%
调整 (|55|≥40): 0.85
最终: 62%
```

## 快速检查清单

完成评分后，确认:

- [ ] 四大维度均已评分 (即使为0也明确标注)
- [ ] 每个非零得分都有判定条件支撑
- [ ] 总分 = 各维度之和 (检查计算)
- [ ] 分类符合总分区间和必要条件
- [ ] 置信度计算有明确步骤
- [ ] 关键证据与评分卡信号一一对应
- [ ] 所有数值都有单位/日期/比较基准
- [ ] 吸筹结论下无未解释的派发高分信号
- [ ] 派发结论下无未解释的吸筹高分信号
