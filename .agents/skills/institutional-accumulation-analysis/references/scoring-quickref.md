# 评分卡快速参考表

本文档提供评分卡的核心阈值和计算规则，供分析时快速查阅。

---

## 四维评分速查

### VSA 量价分析 (±25分)

| 吸筹信号 | 得分 | 核心条件 |
|---------|------|---------|
| 弹簧模式 | +10 | 假跌破+收回+放量(>120%)+长下影 |
| 强势突破 | +8 | 突破>3%+放量(>150%)+收高位+破趋势线 |
| 量缩整理 | +7 | 整理3日++振幅<2%+缩量(<50%)+实体缩小 |

| 派发信号 | 扣分 | 核心条件 |
|---------|------|---------|
| 放量滞涨 | -10 | 放量(>150%)+涨幅<1%+上影>实体2倍+在高位 |
| 上抛失败 | -8 | 假突破+回落+放量+次日低开 |
| 量增下跌 | -7 | 放量(>130%)+跌>2%+收低位+破支撑 |

**关键阈值:**
- 放量: >150% 20日均量
- 缩量: <50% 20日均量
- 弹簧: 跌破>2%，收回，下影>实体2倍

### 技术指标背离 (±25分)

#### OBV 背离

| 类型 | 得分 | 条件 |
|------|------|------|
| 强底背离 | +10 | 价格新低+OBV高>3%+3个低点+破趋势线 |
| 弱底背离 | +6 | 价格10日新低+OBV未新低 |
| 强顶背离 | -10 | 价格新高+OBV低>3%+3个高点+破趋势线 |
| 弱顶背离 | -6 | 价格10日新高+OBV未新高 |

#### CMF 趋势

| 范围 | 得分 | 含义 |
|------|------|------|
| >+0.25 | +8 | 强烈买入 |
| 0~+0.25 | +5 | 温和买入 |
| -0.25~0 | -5 | 温和卖出 |
| <-0.25 | -8 | 强烈卖出 |

#### VWAP 位置

| 状态 | 得分 | 条件 |
|------|------|------|
| 强势支撑 | +7 | 价格>VWAP+2次回调反弹+>VWAP2% |
| 温和支撑 | +4 | 价格>VWAP+1次测试 |
| 中性 | 0 | 价格VWAP±1% |
| 温和阻力 | -4 | 价格<VWAP+1次反弹遇阻 |
| 强势阻力 | -7 | 价格<VWAP+2次反弹回落+>VWAP2% |

#### RSI 背离
- 底背离: +3 (价格新低+RSI抬>5点)
- 顶背离: -3 (价格新高+RSI降>5点)

## 总分与分类

### 分类区间

| 分类 | 总分 | 必要条件 | 标记 |
|------|------|---------|------|
| 强力吸筹 | +75~+100 | (VSA≥+10 且 技术≥+5) 或 (VSA≥+5 且 技术≥+10) | 🔴 |
| 温和吸筹 | +50~+74 | VSA≥+5 或 技术≥+5 或 任一维度≥+20 | 🟡 |
| 观望 | -49~+49 | 无明显方向 | ⚪ |
| 派发初级 | -74~-50 | VSA≤-5 或 技术≤-5 或 任一维度≤-20 | 🟠 |
| 疯狂出货 | -100~-75 | (VSA≤-10 且 技术≤-5) 或 (VSA≤-5 且 技术≤-10) | 🔴 |

### 特殊情况处理

| 情况 | 处理规则 |
|------|---------|
| 信号冲突 | VSA与技术指标方向相反且都>10 → 降观望，置信度×0.6 |
| 单一维度极端 | 一维>20，其他<10 → 置信度×0.7 |
| 数据缺失 | 缺失维度=0，完整性加成减少 |

## 置信度计算

### 公式
```
置信度 = (50% + 证据加成 + 强度加成 + 完整性加成) × 调整系数
范围: 30%-95%
```

### 证据加成表

| 强证据(>8) | 中证据(=8) | 弱证据(<8) | 加成 |
|-----------|-----------|-----------|------|
| ≥5 | 任何 | 任何 | +25% |
| 4 | ≥1 | 任何 | +22% |
| 4 | 0 | ≥2 | +20% |
| 4 | 0 | ≤1 | +18% |
| 3 | ≥2 | 任何 | +17% |
| 3 | 1 | 任何 | +15% |
| 3 | 0 | ≥2 | +12% |
| 3 | 0 | ≤1 | +10% |
| 2 | ≥2 | 任何 | +12% |
| 2 | 1 | 任何 | +10% |
| 2 | 0 | ≥2 | +8% |
| 2 | 0 | ≤1 | +5% |
| 1 | ≥2 | 任何 | +5% |
| 1 | ≤1 | ≥1 | +3% |
| 1 | 0 | 0 | +1% |
| 0 | 任何 | 任何 | 0% |

**强证据**: 权重>8分  **中证据**: 权重=8分  **弱证据**: 权重<8分

### 强度加成

| 最大维度得分 | 加成 |
|--------------|------|
| ≥20 | +10% |
| 15-19 | +7% |
| 10-14 | +5% |
| <10 | 0% |

### 完整性加成

| 数据完整度 | 加成 |
|-----------|------|
| 100% (4/4) | +5% |
| 75% (3/4) | +3% |
| 50% (2/4) | +1% |
| <50% | 0% |

### 调整系数

| 总分绝对值 | 系数 |
|-----------|------|
| ≥80 | 1.0 |
| 60-79 | 0.95 |
| 40-59 | 0.85 |
| <40 | 0.75 |

## 机构成本区间

### 吸筹场景
```
成本下限 = min(20日低点, VWAP×0.98)
成本上限 = max(当前价×0.95, VWAP×1.02)

位置% = (当前价-下限)/(上限-下限) × 100%
```

### 派发场景
```
派发下限 = 近期高点 × 0.95
派发上限 = 近期高点

进度% = (上限-当前价)/(上限-下限) × 100%
```

## 评分卡使用流程图

```
1. 收集数据
   ↓
2. 四维评分 (每维±25分)
   ├─ VSA: 吸筹/派发信号
   ├─ 技术: OBV+CMF+VWAP+RSI
   ├─ 盘口: 暗池+大宗+冰山
   └─ 期权: Call+Put+P/C+Skew
   ↓
3. 计算总分 (-100~+100)
   ↓
4. 确定分类 (按区间+必要条件)
   ↓
5. 计算置信度 (50%+加成)×系数
   ↓
6. 质量检查 (一致性/可追溯)
   ↓
7. 生成报告
```
