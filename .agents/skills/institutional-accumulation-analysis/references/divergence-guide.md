# Technical Indicator Divergence Guide

> **注意**: 本文档描述技术指标背离的定性特征。进行评分卡量化分析时，请参考下方【评分卡量化标准】部分的 thresholds。

## 评分卡量化标准速查

| 背离类型 | 评分卡权重 | 量化阈值 (来自 scoring-system.md) |
|---------|-----------|----------------------------------|
| **OBV强底背离** | +10分 | 价格20日新低(跌>5%) + OBV高>3% + 3个低点 + 破趋势线 |
| **OBV弱底背离** | +6分 | 价格10日新低 + OBV未新低(<3%) + 2个低点 |
| **OBV强顶背离** | -10分 | 价格20日新高(涨>5%) + OBV低>3% + 3个高点 + 破趋势线 |
| **OBV弱顶背离** | -6分 | 价格10日新高 + OBV未新高(<3%) + 2个高点 |
| **RSI底背离** | +3分 | 价格新低 + RSI抬高>5点 |
| **RSI顶背离** | -3分 | 价格新高 + RSI降低>5点 |

## OBV (On-Balance Volume) 背离分析

###  bullish Divergence (看涨背离/吸筹信号) / OBV强底背离
**定义：**
价格创出新低（20日新低，跌幅>5%），但OBV未能创出新低，形成更高的低点（差距>3%）。

**图示：**
```
Price:     OBV:
  ↓ 低      ↑ 高
    ↘      ↗
      ↘   ↗
        ↘ ↗
         高
```

**市场含义：**
- 价格下跌但成交量在上涨日更大
- 机构正在悄悄吸筹
- 下跌动能衰竭

**确认信号：**
1. OBV突破下降趋势线上轨
2. 价格开始企稳或反弹
3. 成交量在上涨时放大
4. 至少3个价格低点确认

**评分卡标准:** 
- **强底背离 (+10分)**: 满足4项条件
- **弱底背离 (+6分)**: 价格10日新低 + OBV未创新低(<3%) + 2个低点

**可靠度：** ⭐⭐⭐⭐⭐

---

### Bearish Divergence (看跌背离/派发信号) / OBV强顶背离
**定义：**
价格创出新高（20日新高，涨幅>5%），但OBV未能创出新高，形成更低的高点（差距>3%）。

**图示：**
```
Price:     OBV:
  ↑ 高      ↓ 低
    ↗      ↘
   ↗      ↘
  ↗      ↘
 ↗      ↘
低
```

**市场含义：**
- 价格上涨但成交量在下跌日更大
- 机构正在悄悄出货
- 上涨动能衰竭

**确认信号：**
1. OBV跌破上升趋势线下轨
2. 价格开始滞涨或回落
3. 成交量在下跌时放大
4. 至少3个价格高点确认

**评分卡标准:** 
- **强顶背离 (-10分)**: 满足4项条件
- **弱顶背离 (-6分)**: 价格10日新高 + OBV未创新高(<3%) + 2个高点

**可靠度：** ⭐⭐⭐⭐⭐

---

### OBV Trend Analysis

**上升趋势：**
- OBV持续创出新高点和更高的低点
- 价格与OBV同步上升 = 健康趋势
- 即使价格回调，OBV维持高位 = 强势整理

**下降趋势：**
- OBV持续创出新低点和更低的高点
- 价格与OBV同步下降 = 健康下跌
- 即使价格反弹，OBV维持低位 = 弱势反弹

**横盘整理：**
- OBV在一定区间内波动
- 等待突破方向确认

## CMF (Chaikin Money Flow) 分析

### 计算公式
CMF = (Close - Low) - (High - Close) / (High - Low) × Volume

### 解读标准

**CMF > +0.25**
- 强烈买入压力
- 机构积极吸筹
- 可持续的上涨趋势

**CMF between 0 and +0.25**
- 温和买入压力
- 买盘主导但不够强烈
- 可能上涨但力度有限

**CMF between -0.25 and 0**
- 温和卖出压力
- 卖盘主导但不够强烈
- 可能下跌但力度有限

**CMF < -0.25**
- 强烈卖出压力
- 机构积极派发
- 可持续的下跌趋势

### CMF Divergence

**Bullish Divergence:**
- 价格创新低，CMF形成更高的低点
- 卖压在减弱，买盘开始介入
- 潜在的底部反转信号

**Bearish Divergence:**
- 价格创新高，CMF形成更低的高点
- 买压在减弱，卖盘开始增加
- 潜在的顶部反转信号

## VWAP (Volume Weighted Average Price) 分析

### 基本概念
VWAP = Σ(Price × Volume) / Σ(Volume)

代表机构平均持仓成本，是判断机构意图的关键指标。

### 位置关系解读

**Price > VWAP**
- 当前价格高于机构成本
- 机构处于浮盈状态
- 倾向于看涨或持有
- 回调至VWAP可能是买入机会

**Price < VWAP**
- 当前价格低于机构成本
- 机构处于浮亏状态
- 可能继续下跌或机构会护盘
- 反弹至VWAP可能遇阻

**Price ≈ VWAP**
- 价格围绕VWAP震荡
- 多空双方势均力敌
- 等待方向选择

### VWAP标准差通道

**+1σ 至 +2σ (上轨区)**
- 短期超买区域
- 可能出现回调
- 派发区域之一

**-1σ 至 -2σ (下轨区)**
- 短期超卖区域
- 可能出现反弹
- 吸筹区域之一

**±3σ (极端区)**
- 统计上罕见的价格行为
- 强烈反转信号
- 机构极度过激行为

### VWAP Reversion Strategy

**Mean Reversion Setup:**
1. 价格偏离VWAP超过2σ
2. 成交量萎缩
3. 出现反转K线形态
4. 目标回到VWAP

**Trend Following Setup:**
1. 价格持续在VWAP上方运行
2. 每次回调至VWAP获得支撑
3. VWAP斜率向上
4. 顺势做多

## RSI Divergence (补充确认)

### Bullish RSI Divergence / RSI底背离
**条件：**
- 价格创出新低
- RSI形成更高的低点（未创新低，抬高>5点）

**意义：**
下跌动能减弱，与OBV背离形成共振时可靠性更高

**评分卡标准:** 满足条件得 **+3分**

### Bearish RSI Divergence / RSI顶背离
**条件：**
- 价格创出新高
- RSI形成更低的高点（未创新高，降低>5点）

**意义：**
上涨动能减弱，与OBV背离形成共振时可靠性更高

**评分卡标准:** 满足条件得 **-3分**

## MACD Divergence (趋势确认)

### Bullish MACD Divergence
**条件：**
- 价格创出新低
- MACD柱状图或DIF线形成更高的低点

**意义：**
中长期趋势可能反转，比RSI背离更具趋势性

### Bearish MACD Divergence
**条件：**
- 价格创出新高
- MACD柱状图或DIF线形成更低的高点

**意义：**
中长期趋势可能见顶，适合波段交易者

## 多指标背离共振

### 最强吸筹信号组合
1. **Price** - 价格处于低位或创出新低
2. **OBV** - 形成更高的低点（bullish divergence）
3. **CMF** - 从负值回升或形成底背离
4. **RSI** - 形成底背离
5. **Volume** - 下跌缩量，上涨放量

**可靠度：** ⭐⭐⭐⭐⭐

### 最强派发信号组合
1. **Price** - 价格处于高位或创出新高
2. **OBV** - 形成更低的高点（bearish divergence）
3. **CMF** - 从正值回落或形成顶背离
4. **RSI** - 形成顶背离
5. **Volume** - 上涨缩量，下跌放量

**可靠度：** ⭐⭐⭐⭐⭐

### 需要注意的假信号
- 单一指标背离，其他指标不配合
- 背离发生在极强趋势中（可能持续背离）
- 背离后没有足够的成交量确认
- 大盘环境不支持反转

---

## 背离失效的常见原因

1. **时间周期不匹配**
   - 日线级别背离，周线级别无背离
   - 建议多周期验证

2. **极端趋势**
   - 抛物线上涨中，顶背离可能持续多次才生效
   - 恐慌性下跌中，底背离可能持续多次才生效

3. **成交量不配合**
   - 背离需要成交量变化确认
   - 无量背离往往失败

4. **重大消息干扰**
   - 突发利好/利空可能使技术背离失效
   - 需结合基本面变化
