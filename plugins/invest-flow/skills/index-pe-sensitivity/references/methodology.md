# 指数估值敏感性分析方法论

把「指数价格涨跌 → 估值倍数变化 → N 年历史分位」串成一张敏感性表,用于快速回答:
**"如果指数再涨/跌 X%,估值会到历史什么位置?"**

---

## 1. 数据口径铁律(先锁定,错了整表作废)

1. **全程单一口径**:当前倍数、N 年历史序列、分位数,三者必须**同源同口径**。混口径会让分位数失效——这是最容易犯、也最致命的错。
2. **基准口径 = 指数整体法**:`TTM P/E = Σ总市值 ÷ Σ滚动净利润`(含全部成分)。
   - A 股优先 **东方财富 Choice**;取不到时用同族整体法源(中证指数官方、理杏仁「市值加权」、乐咕乐股),并显式标注来源。
   - 美股指数优先能给「指数级整体口径」的源。
3. **不要用 ETF 资料页口径**(如 QQQ 的加权谐波均值 + 剔除负盈利 + 个股 P/E 封顶):它本身不算错(Morningstar 也用谐波均值),但绝对值系统性低约 3–4 点,**与整体法口径不可直接混用/比较**。
4. **不要用算术平均值口径**(成分 P/E 简单平均):会被少数超高 P/E 个股拉爆(科创50 平均值口径能到 120+ 而整体法/等权是另一个数),严重失真。
5. **分位用 N 年经验分位**(真实历史排名),不要用正态近似(σ 换算)。正态法在分布左偏/双峰时会系统性偏差。
6. 所有数值标注**日期与来源**;非当日要说明。

### 常见口径对照(同一指数、同一天可以差一倍)

| 口径 | 定义 | 特点 |
|---|---|---|
| **整体法 / 市值加权** | Σ市值 ÷ Σ净利润(= 加权谐波均值) | 基准口径;含全部成分,盈利周期底时会被动抬高 |
| 等权 | Σ(个股 P/E) ÷ 股票数 | 削弱大市值低盈利股绑架 |
| 正数等权 | 仅正盈利成分等权 | 规避亏损成分 |
| 算术平均值 | 成分 P/E 简单平均 | 被高 P/E 离群值拉爆,**不用** |
| ETF 资料页 | 谐波均值 + 剔亏 + 封顶 | 系统性偏低,**不与整体法混用** |

---

## 2. 计算步骤

1. 取截止日指数 **TTM P/E₀(整体法)** 作为基准,及其 **N 年经验分位**。
2. 对每个价格档位 m(默认 +10% / +5% / 0 / −5% / −10%):
   - `新 P/E = P/E₀ × (1 + m)`
     价格线性传导,**TTM 盈利视为不变**(短周期快照假设,不是前瞻盈利预测)。
   - 把新 P/E 映射到 N 年历史分布 → 经验分位。
3. 组表:情景 | TTM P/E | N 年分位数 | 较现在(分位变化 pt)。

### 分位映射的两种实现

- **历史序列(首选)**:拿到 N 年逐日/逐周 P/E 序列,直接算经验分位(某值的分位 = 序列中 ≤ 该值的占比)。脚本 `--series-file`。
- **分位锚点插值(次选)**:只拿到 min / 20% / 50% / 80% / max + 当前分位时,按分段线性插值。脚本 `--anchors`。**注意顶/底部区间锚点稀疏,插值较粗略,要显式标注。**

---

## 3. 解读要点(必答三条)

1. **当前分位定位**:>90% 极端偏高 / 70–90% 偏高 / 30–70% 中性 / <30% 偏低。
2. **不对称性**:上涨档 vs 下跌档的分位走向——上方是否很快触顶、下方是否快速释放。
3. **敏感度 / 曲线形态**:价格每 ±5% 分位摆动约几个点。
   - **陡峭型**(如纳指:±5% → 分位 ±20~26 点):分布密集区,估值对价格高度敏感。
   - **钝化型**(如科创50 顶部:±10% 分位才动几个点):已在极值,分位对价格几乎不反应。

---

## 4. 失真检查:整体法 PE 何时"破损"

整体法在**盈利稳定**的指数上很好用(如纳指,盈利平滑);但在**盈利处于周期底**的板块会失真:

- 机理:Σ净利润 被周期性压小 → `Σ市值÷Σ净利润` 被动放大 → P/E 极高、分位顶到 90%+。
- 信号:P/E **月内剧烈摆动**(如科创50 一个月 157→264→232),说明是**分母不稳**而非价格驱动。
- 后果:此时"高分位 ≠ 单纯极度高估",而是"贵 + 盈利在周期底"的叠加,顶部还会**钝化**(分位对价格失去区分度)。

**处置**:选指数时先判断成分盈利是否在周期底。若是(半导体、硬科技、强周期),优先或并列使用更稳的尺:

| 备选口径 | 适用理由 |
|---|---|
| 等权 / 正数等权 PE | 削弱大市值低盈利股对整体法的绑架 |
| PB(市净率) | 盈利失真时,净资产更稳,周期底常用 |
| PS(市销率) | 硬科技看收入更能穿越盈利周期 |
| Forward PE / 剔除亏损 PE | 用预期或正盈利成分,避开周期底分母 |

同一敏感性框架可直接套在 PB / PS 上(把"倍数"换掉即可)。
