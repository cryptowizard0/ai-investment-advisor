# 机构吸筹派发分析评分卡系统 (Scoring Card System)

## 概述

本评分卡系统将主观的技术分析转化为**可量化、可验证、可复现**的客观评分体系，确保不同模型对同一组数据得出一致的结论。

**总分范围**: -100 ~ +100 分  
**分类阈值**: 确定性区间划分，无模糊地带  
**置信度计算**: 基于证据数量和质量，非主观估算

---

## 一、四维评分矩阵

### Dimension 1: 量价分析 (VSA) - 满分 25 分

#### 吸筹信号 (正向得分)

| 信号 | 权重 | 判定条件 (必须全部满足) | 得分 |
|------|------|------------------------|------|
| **弹簧模式 (Spring)** | 10分 | ① 价格短暂跌破关键支撑位 (>2%)<br>② 当日收于支撑位上方或附近<br>③ 成交量放大 (>120%均量)<br>④ 下影线长度 > 实体长度 2倍 | 完全满足: 10分<br>满足3项: 6分<br>满足2项: 3分<br>其他: 0分 |
| **强势突破 (SOS)** | 8分 | ① 大阳线突破关键阻力 (>3%涨幅)<br>② 成交量 >150% 20日均量<br>③ 收盘价位于当日高点80%以上<br>④ 突破下降趋势线 | 完全满足: 8分<br>满足3项: 5分<br>满足2项: 2分<br>其他: 0分 |
| **量缩整理 (Test)** | 7分 | ① 连续3日+窄幅整理 (振幅<2%)<br>② 成交量 <50% 20日均量<br>③ 发生在支撑位附近<br>④ K线实体逐渐缩小 | 完全满足: 7分<br>满足3项: 4分<br>满足2项: 2分<br>其他: 0分 |

#### 派发信号 (负向扣分)

| 信号 | 权重 | 判定条件 (必须全部满足) | 扣分 |
|------|------|------------------------|------|
| **放量滞涨 (Stall)** | -10分 | ① 成交量 >150% 20日均量<br>② 价格涨幅 <1% (或收阴)<br>③ 出现在近期高点或阻力位<br>④ 上影线长度 > 实体长度 2倍 | 完全满足: -10分<br>满足3项: -6分<br>满足2项: -3分<br>其他: 0分 |
| **上抛失败 (Upthrust)** | -8分 | ① 假突破关键阻力位 (>2%突破)<br>② 收盘价回到阻力下方<br>③ 成交量放大但价格回落<br>④ 次日低开或继续下跌 | 完全满足: -8分<br>满足3项: -5分<br>满足2项: -2分<br>其他: 0分 |
| **量增下跌** | -7分 | ① 成交量 >130% 20日均量<br>② 价格下跌 >2%<br>③ 收盘价接近当日低点<br>④ 跌破短期均线支撑 | 完全满足: -7分<br>满足3项: -4分<br>满足2项: -2分<br>其他: 0分 |

#### VSA 维度计分规则

```
VSA原始分 = 吸筹信号得分 + 派发信号扣分

if VSA原始分 > 25:
    VSA最终分 = 25
elif VSA原始分 < -25:
    VSA最终分 = -25
else:
    VSA最终分 = VSA原始分
```

## 二、总分计算与分类

### 总分计算公式

```
总分 = VSA最终分 + 技术最终分 + 盘口最终分 + 期权最终分

总分范围: -100 ~ +100
```

### 诊断分类标准 (确定性规则)

| 分类 | 总分区间 | 必要条件 | 标记 |
|------|---------|---------|------|
| **强力吸筹** | +75 ~ +100 | ① 总分 ≥ 75<br>② **(VSA ≥ +10 且 技术 ≥ +5) 或 (VSA ≥ +5 且 技术 ≥ +10)** | 🔴 强力吸筹 |
| **温和吸筹** | +50 ~ +74 | ① 总分 ≥ 50<br>② **(VSA ≥ +5 或 技术 ≥ +5 或 任一维度 ≥ +20)** | 🟡 温和吸筹 |
| **观望/中性** | -49 ~ +49 | ① 总分在 -49 到 +49 之间<br>② 无明显方向性信号 | ⚪ 观望 |
| **派发初级** | -74 ~ -50 | ① 总分 ≤ -50<br>② **(VSA ≤ -5 或 技术 ≤ -5 或 任一维度 ≤ -20)** | 🟠 派发初级 |
| **疯狂出货** | -100 ~ -75 | ① 总分 ≤ -75<br>② **(VSA ≤ -10 且 技术 ≤ -5) 或 (VSA ≤ -5 且 技术 ≤ -10)** | 🔴 疯狂出货 |

#### 单一维度极端例外条款

当某一维度出现极端信号但总分未达标准时，启用例外条款：

```
if VSA ≥ +20 且 总分 < +50:
    分类 = "温和吸筹"
    置信度 = 计算置信度 × 0.7
    备注 = "VSA单一维度极端信号，其他维度配合不足"

if 技术 ≥ +20 且 总分 < +50:
    分类 = "温和吸筹"
    置信度 = 计算置信度 × 0.7
    备注 = "技术指标单一维度极端信号，量价配合不足"

if VSA ≤ -20 且 总分 > -50:
    分类 = "派发初级"
    置信度 = 计算置信度 × 0.7
    备注 = "VSA单一维度极端派发信号"

if 技术 ≤ -20 且 总分 > -50:
    分类 = "派发初级"
    置信度 = 计算置信度 × 0.7
    备注 = "技术指标单一维度极端派发信号"
```

### 特殊情况处理

#### 1. 信号冲突 (Conflict)
当满足以下任一条件时，判定为"信号冲突"，降级处理：

```
if (VSA > 0 且 技术 < 0) 或 (VSA < 0 且 技术 > 0):
    if |VSA| > 10 且 |技术| > 10:
        分类 = "观望"
        置信度 = 基础置信度 × 0.6
        备注 = "VSA与技术指标信号冲突，需进一步观察"
```

#### 2. 单一维度极端
当某一维度极端但其他维度无信号：

```
if (任一维度绝对值 > 20) 且 (其他三维绝对值之和 < 10):
    分类 = 按总分区间分类
    置信度 = 基础置信度 × 0.7
    备注 = "依赖单一维度信号，可靠性中等"
```

#### 3. 数据缺失
当某维度数据缺失时：

```
if 期权数据缺失:
    期权最终分 = 0
    总分计算时注释 = "期权数据缺失，总分基于三维计算"
    置信度 = 基础置信度 × 0.85
```

## 三、置信度计算

### 基础置信度公式

```
基础置信度 = 50% + f(证据数量) + f(信号强度) + f(数据完整性)
```

### 1. 证据数量加成 (Evidence Count)

#### 证据强度定义 (修订版)

为避免歧义，采用**严格大于**定义：

| 证据级别 | 权重范围 | 示例 |
|---------|---------|------|
| **强证据** | 权重 **> 8分** (即9分及以上) | 弹簧(+10)、OBV强背离(+10) |
| **中证据** | 权重 **= 8分** | 强势突破(+8)、CMF强势(+8) |
| **弱证据** | 权重 **< 8分** (即7分及以下) | 量缩整理(+7)、VWAP温和(+4) |

#### 证据加成表 (修订版)

| 强证据(>8) | 中证据(=8) | 弱证据(<8) | 加成 |
|-----------|-----------|-----------|------|
| ≥5 | 任何 | 任何 | +25% |
| 4 | ≥1 | 任何 | +22% |
| 4 | 0 | ≥2 | +20% |
| 4 | 0 | ≤1 | +18% |
| 3 | ≥2 | 任何 | +17% |
| 3 | 1 | 任何 | +15% |
| 3 | 0 | ≥2 | +12% |
| 3 | 0 | ≤1 | +10% |
| 2 | ≥2 | 任何 | +12% |
| 2 | 1 | 任何 | +10% |
| 2 | 0 | ≥2 | +8% |
| 2 | 0 | ≤1 | +5% |
| 1 | ≥2 | 任何 | +5% |
| 1 | ≤1 | ≥1 | +3% |
| 1 | 0 | 0 | +1% |
| 0 | 任何 | 任何 | 0% |

**使用示例:**
- 3个强证据(>8) + 2个中证据(=8) → 查表第6行 → **+17%**
- 2个强证据(>8) + 1个中证据(=8) + 3个弱证据(<8) → 查表第10行 → **+10%**

### 2. 信号强度加成 (Signal Strength)

```
最大单一维度得分 = max(|VSA|, |技术|, |盘口|, |期权|)

if 最大单一维度得分 ≥ 20:
    强度加成 = +10%
elif 最大单一维度得分 ≥ 15:
    强度加成 = +7%
elif 最大单一维度得分 ≥ 10:
    强度加成 = +5%
else:
    强度加成 = 0%
```

### 3. 数据完整性加成 (Data Completeness)

```
数据完整度 = (有数据的维度数 / 4) × 100%

if 数据完整度 = 100%:
    完整性加成 = +5%
elif 数据完整度 ≥ 75%:
    完整性加成 = +3%
elif 数据完整度 ≥ 50%:
    完整性加成 = +1%
else:
    完整性加成 = 0%
```

### 4. 最终置信度计算

```
原始置信度 = 50% + 证据加成 + 强度加成 + 完整性加成

# 根据总分调整
if |总分| ≥ 80:
    调整系数 = 1.0
elif |总分| ≥ 60:
    调整系数 = 0.95
elif |总分| ≥ 40:
    调整系数 = 0.85
else:
    调整系数 = 0.75

最终置信度 = 原始置信度 × 调整系数

# 边界限制
最终置信度 = max(30%, min(95%, 最终置信度))
```

### 置信度等级

| 置信度 | 等级 | 建议 |
|--------|------|------|
| 85-95% | 极高 | 高置信度交易信号 |
| 70-84% | 高 | 可靠信号，可执行 |
| 55-69% | 中等 | 需要确认，小仓位试探 |
| 40-54% | 低 | 信号模糊，观望为主 |
| 30-39% | 极低 | 不建议基于此交易 |

## 四、机构成本区间估计

### 吸筹场景成本区间计算

```
吸筹成本下限 = min(近20日低点, VWAP × 0.98)
吸筹成本上限 = max(当前价格 × 0.95, VWAP × 1.02)

当前位置评估 = ((当前价格 - 吸筹成本下限) / (吸筹成本上限 - 吸筹成本下限)) × 100%

if 当前位置评估 < 0:
    评估 = "低于成本区 " + abs(当前位置评估) + "%"
elif 当前位置评估 > 100:
    评估 = "高于成本区 " + (当前位置评估 - 100) + "%"
else:
    评估 = "处于成本区 " + 当前位置评估 + "%"
```

### 派发场景成本区间计算

```
派发区间下限 = 近期高点 × 0.95
派发区间上限 = 近期高点

派发进度 = ((派发区间上限 - 当前价格) / (派发区间上限 - 派发区间下限)) × 100%

if 派发进度 < 0:
    评估 = "尚未开始派发"
elif 派发进度 > 100:
    评估 = "派发已完成 (>100%)"
else:
    评估 = "派发进度 " + 派发进度 + "%"
```

## 七、常见问题解答

### Q1: 如果多个信号同时出现，如何计分？
**A**: 累加计分，但每个维度有±25分的上限。例如VSA维度同时出现弹簧(+10)和放量滞涨(-10)，净得分为0。

### Q2: 数据不完整时如何处理？
**A**: 缺失维度计0分，并在报告中注明。置信度会相应降低 (完整性加成减少)。

### Q3: 模型对"关键支撑/阻力"理解不同怎么办？
**A**: 在分析中明确定义：
- 关键支撑 = 近20日低点 或 前期多次测试的价位
- 关键阻力 = 近20日高点 或 前期多次测试的价位
- 提供具体价格区间，避免模糊表述

### Q4: 如何处理边缘情况 (如总分49分)？
**A**: 严格按区间划分：
- 49分 → 观望
- 50分 → 温和吸筹
不存在"介于两者之间"的分类

### Q5: 置信度能否达到100%？
**A**: 不能。系统设计上限为95%，因为市场永远存在不确定性。即使所有信号完美对齐，也保留5%的不确定性空间。
