# 指数牛熊周期表方法

## 1. 核心定义

默认阈值为 20%，全部使用**日收盘价**：

- 牛市从一个已确认谷底回溯开始；当价格较该谷底上涨至少 20% 时得到确认。
- 牛市在后续最高收盘日结束；当价格较最高收盘回撤至少 20% 时，牛市结束得到确认，同时熊市从该最高收盘日回溯开始。
- 熊市从一个已确认峰值回溯开始；当价格较该峰值下跌至少 20% 时得到确认。
- 熊市在后续最低收盘日结束；当价格较最低收盘反弹至少 20% 时，熊市结束得到确认，同时牛市从该最低收盘日回溯开始。

确认日与周期终止日通常不同。表格写峰/谷的**终止日**；必要时在计算依据中另写“确认日”。

阈值只是可重复的统计规则，不等同于基本面周期结论。若用户另有阈值，显式记录并用同一阈值重算全表。

## 2. 当前周期

未完成周期也可以入表，但必须标记“本轮至今”：

- 当前牛市的终止日列写截至数据截止日的最高收盘日。
- 当前熊市的终止日列写截至数据截止日的最低收盘日。
- 持续天数和幅度均算到该暂定极值日，而不是机械算到分析日。
- 在脚注明暂定极值可能被未来新高或新低替换。

一旦反向 20% 阈值触发，上一周期转为已完成；对向表新增一条从上一极值日开始的当前周期。即使随后一天站回阈值线，也不撤销已经发生的技术确认。

## 3. 计算公式

- 持续天数：`终止日 - 起始日` 的自然日差，不含首尾加一。
- 牛市幅度：`峰值收盘 / 谷值收盘 - 1`。
- 熊市幅度：`谷值收盘 / 峰值收盘 - 1`。
- 当前回撤：`最新收盘 / 最近峰值收盘 - 1`。
- 当前反弹：`最新收盘 / 最近谷值收盘 - 1`。

显示时沿用报告精度；计算和判断使用未四舍五入原值。

## 4. P/E 规则

- P/E 是周期极值的估值注释，不是周期确认条件。
- 优先取峰/谷当日的指数级 TTM P/E；同一报告内保持供应商、聚合算法、盈利口径和成分处理一致。
- 不得将 ETF 资料页 P/E、指数整体法 P/E、成分股算术平均 P/E 混用。
- 若最近可得 P/E 日期与极值日只隔很短且期间没有新的盈利披露，可用：
  `极值日估算 P/E = 最近观测 P/E × 极值日指数收盘 / 最近观测日指数收盘`。
- 所有估算值加 `≈`，同时披露日期、公式和“TTM 盈利不变”假设。

## 5. 均值与历史表

- 历史均值只统计已完成周期。
- 进行中的当前周期不参与持续天数、幅度或 P/E 均值。
- 原始历史表缺少 P/E 时保留 `—`，不要为了填满表格混入另一口径。
- 对图片转录的旧表，先复核日期、天数和幅度；不能复核的数据标记“沿用原表”。

## 6. 新指数与现有指数

### 更新现有指数

1. 从最后一个已确认峰/谷开始获取价格。
2. 用 `seed-kind` 固定起始方向。
3. 更新当前行；若发生反向确认，关闭旧行并在对向表新增当前行。
4. 原地更新稳定文件名，不另建日期副本。

### 新建指数

1. 获取足够长的 EOD 历史，优先覆盖完整市场结构周期。
2. 使用 `seed-kind auto` 初筛 20% 峰谷。
3. 人工检查指数重定基、休市、数据断层和异常值。
4. 分拆为牛市表和熊市表，并用模板生成稳定文件。

## 7. 数据与证据优先级

1. 指数公司或交易所官方历史收盘。
2. 获授权的主流行情供应商。
3. 可靠财经数据库，作为缺口回退或交叉验证。

原因归因优先公司财报、央行/政府、行业协会和权威通讯社。若多个因素并存，用“主要原因/市场归因”而不是单一确定因果。

## 8. 更新检查表

- [ ] 分析日期与最新完整交易日分别标注。
- [ ] 价格序列单一来源，零值和重复日期已清理。
- [ ] 峰谷均为收盘价极值，未混用盘中高低。
- [ ] 20% 判断使用未四舍五入数字。
- [ ] 牛熊两表的共享转折日期一致。
- [ ] P/E 同源；估算值有 `≈` 和公式。
- [ ] 当前周期未计入历史均值。
- [ ] 原因有来源并区分事实与推断。
- [ ] 文件写入 `output/monitor/` 且稳定命名。
