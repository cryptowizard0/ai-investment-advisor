# 专业投资分析师 Methodology

## 核心原则

以“可验证、可修正、可跟踪”为目标组织研究。避免百科式介绍；所有判断都要回到证据、假设、反证条件和后续跟踪指标。

## 证据标记

在报告中对关键陈述使用以下标记：

| 标记 | 含义 | 使用要求 |
|---|---|---|
| 事实 | 可由公告、财报、权威数据源或公司文件验证 | 标注时间点和来源 |
| 推断 | 基于事实做出的分析判断 | 写清推理链条 |
| 假设 | 估值、情景分析或未来判断所依赖的变量 | 写清变量、方向和失效条件 |
| 不确定 | 暂时无法可靠确认的数据或关系 | 不得用模糊数字替代 |

## 八层研究框架

### 第一层：事实层

回答：
- 公司是谁？
- 做什么业务？
- 收入结构是什么？
- 客户是谁？
- 竞争对手是谁？
- 最近 5 年关键财务数据如何？

输出要求：
- 公司定义必须一句话讲清“为谁、解决什么问题、如何收费”。
- 收入结构尽量拆到 segment、region、product 或 customer type。
- 财务数据至少覆盖 Revenue、Gross Margin、Operating Income、Net Income、Free Cash Flow、ROIC/ROE、Net Debt/Cash；缺失时标记“不确定”。

### 第二层：商业模式层

回答：
- 公司如何赚钱？
- 收入增长由什么驱动？
- 利润率由什么决定？
- 现金流质量如何？
- 是否有经营杠杆？
- 是否有规模效应？

输出要求：
- 将增长拆成价格、销量、客户数、ARPU、留存、渗透率、产能、渠道或周期因素。
- 说明利润率的主要变量：成本结构、研发/销售费用率、原材料、利用率、mix、定价权。
- 判断现金流质量时区分会计利润与自由现金流。

### 第三层：行业层

回答：
- 行业空间多大？
- 行业处于什么生命周期？
- 需求增长的核心驱动是什么？
- 行业竞争格局如何？
- 行业利润池由谁掌握？

输出要求：
- 明确 TAM/SAM/SOM 或可替代的市场空间口径。
- 判断行业阶段：导入期、成长期、成熟期、衰退期或周期复苏/下行。
- 区分需求真实增长、库存周期、政策刺激和估值叙事。

### 第四层：护城河层

回答：
- 公司为什么能赢？
- 客户为什么不换？
- 竞争对手为什么难以复制？
- 公司优势是变强、变弱，还是稳定？
- 这家公司是否能长期保持高 ROIC？

输出要求：
- 护城河类型可包括网络效应、转换成本、规模经济、品牌、成本优势、数据优势、监管牌照、生态绑定。
- 必须说明护城河如何体现在财务指标或经营指标中。
- 不要把“市占率高”直接等同于护城河；说明可持续性。

### 第五层：财务层

回答：
- 营收增长质量如何？
- 毛利率趋势说明什么？
- 经营利润率是否改善？
- 净利润是否真实？
- 自由现金流是否健康？
- 资产负债表是否安全？

输出要求：
- 关注 5 年趋势，而不是单点数字。
- 解释利润表、现金流量表和资产负债表之间是否相互印证。
- 标记一次性项目、股权激励、重组费用、库存减值、应收账款异常、资本化支出等质量问题。

### 第六层：估值层

回答：
- 当前估值是多少？
- 相对历史贵不贵？
- 相对同业贵不贵？
- 市场当前隐含了什么预期？
- 乐观、基准、悲观情景下分别值多少钱？

输出要求：
- 至少使用一种主估值法和一种交叉验证法，例如 DCF、EV/EBITDA、P/E、P/S、SOTP 或 unit economics。
- 所有估值必须列关键假设：收入 CAGR、目标利润率、FCF margin、折现率、终值增长率、目标倍数或净现金/债务。
- 明确当前股价隐含的增长和利润率预期。

### 第七层：反身性层

回答：
- 市场现在相信什么叙事？
- 股价是否已经提前反映叙事？
- 基本面是否正在验证叙事？
- 是否存在“叙事领先现实”或“现实领先叙事”的情况？
- 哪些数据会强化市场信念？
- 哪些数据会打破市场信念？

输出要求：
- 区分价格走势、市场叙事和基本面验证。
- 判断所处状态：启动、强化、透支、反转。
- 写清边际变化：哪些数据正在改变市场信念。

### 第八层：投资决策层

回答：
- 核心投资假设是什么？
- 未来 6-24 个月催化剂是什么？
- 最大风险是什么？
- 反证条件是什么？
- 应该买入、观望还是卖出？
- 应该一次性买入还是分批跟踪？
- 哪些指标需要持续监控？

输出要求：
- 最终建议只能是：买入 / 观望 / 卖出。
- 给出适合分批跟踪的条件：估值区间、关键数据发布、技术位置或基本面确认点。
- 反证条件必须具体到可观察指标或事件。

## 常用数据源

优先级从高到低：
1. 公司官方文件：10-K、20-F、10-Q、annual report、Investor Relations、earnings release、earnings call transcript。
2. 监管和交易所文件：SEC、交易所公告、监管文件。
3. 权威市场数据：公司公告口径、交易所、主流金融数据源。
4. 行业资料：行业协会、咨询机构、上下游公司披露。
5. 新闻和市场评论：仅用于叙事、催化剂和市场预期，不作为核心财务事实的唯一来源。

## 最低输出标准

- 必须包含 16 个模板章节。
- 必须包含 5 年关键财务表；无法获取时保留表格并标记“不确定”。
- 必须包含三情景估值表。
- 必须包含“事实 / 推断 / 假设”标记。
- 必须包含可执行的跟踪指标 Dashboard。
- 必须给出买入 / 观望 / 卖出。
