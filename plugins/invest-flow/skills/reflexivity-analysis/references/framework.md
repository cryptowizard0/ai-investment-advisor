# 反身性分析框架（深度档）

## 目标

围绕一个主题做完整反身性深度研究，不是静态估值说明，而是判断：
- 当前处于反身性周期哪个阶段
- 是否仍有机会
- 是否已经透支
- 是否存在反转风险

主线必须始终围绕三件事展开：
- 认知
- 价格
- 现实

真正重要的不是三者各自的绝对水平，而是三者之间是否仍在相互强化，还是已经开始错位和脆弱化。

## 分析主链条

### 1. 叙事层
- 先定义市场现在相信什么。
- 再判断这个叙事有多热、多一致、多“宗教化”。
- 若“这次不一样”感显著增强，往往意味着市场正在把周期性现象解释成结构性确定性。

需要观察：
- 媒体热度
- 共识程度
- 散户参与
- 叙事来源

### 2. 行为层
- 叙事只有转化成资金和配置行为，才具备价格推动力。
- 关注的不只是有没有买入，而是买入是试探、追涨、拥挤，还是被迫行为。

常用证据：
- ETF / 基金资金流
- 机构持仓变化
- 融资 / 杠杆
- 一级市场融资热度
- 企业资本开支

### 3. 价格层
- 看价格是否在验证叙事，还是已经领先叙事过远。
- 趋势顺滑往往代表正反馈仍在；波动放大、利好钝化、背离增多，往往意味着脆弱化开始出现。

价格状态可归类为：
- 预期启动
- 正反馈强化
- 预期透支
- 反身性断裂

### 4. 现实层
- 问：如果这个叙事是真的，现实里必须出现什么？
- 必须找 3 个关键、可验证的指标，而不是写泛泛愿景。
- 现实验证不仅看有没有改善，更看改善是否可持续。

每个指标可判断为：
- 没出现
- 刚出现
- 持续强化
- 开始转弱

### 5. 边际变化层
- 反转很少发生在绝对最差时，而通常发生在“仍然很好，但没那么好了”的阶段。
- 所以要重点看：
  - 认知是否过强、怀疑是否出现、新信徒是否减少
  - 价格是否更难创新高、波动是否放大、利空打击是否减弱
  - 现实是否开始减速、利润率改善是否见顶、融资环境是否转紧

## 错位判断

### 类型 A：认知先行，价格未动
- 叙事开始形成，但价格尚未充分反映。
- 往往对应早期机会区。

### 类型 B：价格先行，现实未到
- 市场已经提前交易未来，但现实兑现仍在路上。
- 往往对应趋势中段或泡沫早期。

### 类型 C：价格远超现实，共识极强
- 最典型的高风险区。
- 并不一定立刻下跌，但向上的赔率通常已经下降。

## 周期阶段判断

- 阶段 1：叙事萌芽
- 阶段 2：价格启动
- 阶段 3：正反馈强化
- 阶段 4：透支与脆弱
- 阶段 5：反转与负反馈

阶段判断不能只看价格，要看：
- 叙事强度
- 行为拥挤度
- 现实兑现度
- 边际变化是否开始恶化

## 顶底识别

### 顶部风险区常见特征
- 媒体极度乐观
- 价格涨了很久
- 现实很好
- 但现实改善速度下降
- 融资环境开始收紧
- 新增买家越来越少

### 底部孕育区常见特征
- 新闻极度悲观
- 利润很差
- 价格跌了很久
- 但坏消息不再让价格创新低
- 卖盘衰竭
- 现实开始出现早期改善信号

## 输出纪律

- 必须解释链条：叙事 -> 行为 -> 价格 -> 现实 -> 边际变化。
- 不要停留在抽象判断，尽量落到企业经营、资金行为、价格表现和周期位置。
- 必须标注：
  - 已验证
  - 推断
  - 待验证
- 重点识别“错位”和“边际变化”，因为反转通常发生在这里。
