# 产业链两层分析方法论

## 核心原则

产业链研究不是列公司，而是追踪价值、约束和利润如何在链条中流动。

必须回答：

| 问题 | 输出 |
|---|---|
| 谁最终付钱 | 终端客户、预算来源、采购逻辑 |
| 需求如何传导 | 从下游需求到上游产能/材料/设备的传导链 |
| 价值留在哪 | 收入、毛利、现金流和议价权所在环节 |
| 供给哪里扩不快 | 厂房、设备、材料、人才、技术、认证、监管 |
| 最小瓶颈是什么 | 能独立影响产能、良率、成本、交期或认证的节点 |
| 如何验证 | 订单、交期、ASP、良率、capex、backlog、客户披露 |

## 第一层：产业全景图

第一层的目标是避免漏环节。必须从终端需求倒推。

| 字段 | 要求 |
|---|---|
| 一级模块 | 上游材料/设备、核心零部件、制造/封装、系统集成、渠道/平台、终端客户、服务/运维、生态支撑 |
| 功能 | 该模块解决什么问题 |
| 上游依赖 | 依赖哪些材料、设备、技术、资质或资源 |
| 下游客户 | 谁采购或使用该模块 |
| 需求来源 | 订单、capex、政策、技术路线、客户预算或替代需求 |
| 价值池 | 收入、毛利、现金流、议价权是否集中 |
| 供给弹性 | 扩产周期、设备交期、良率爬坡、认证周期 |
| 代表公司 | 只列真实参与该模块的公司 |
| 跟踪指标 | 订单、交期、ASP、利用率、库存、毛利率、backlog、capex |

第一层输出应当形成一张表，并写出需求传导链，例如：

```text
终端需求增加 -> 系统/整机需求增加 -> 核心模块需求增加 -> 材料/设备/产能瓶颈显性化
```

## 第二层：模块下钻图

第二层的目标是找到真正可验证的瓶颈。对第一层中最关键的 3-8 个模块继续拆解。

| 字段 | 要求 |
|---|---|
| 一级模块 | 来自第一层的模块 |
| 二级节点 | 模块内可独立分析的产品、材料、设备、工艺或测试节点 |
| 产品/子系统 | 具体可销售、可交付或可认证的单元 |
| 工艺步骤 | 制造、封装、测试、认证、交付或运维步骤 |
| 关键材料 | 决定性能、良率、成本或可靠性的材料 |
| 关键设备 | 交期长、调试难、受管制或影响节拍的设备 |
| 技术参数 | 带宽、功耗、热阻、CTE、效率、精度、寿命、可靠性等 |
| 良率变量 | void、warpage、delamination、污染、散热、返工率、失效率等 |
| 供应商格局 | 集中度、替代难度、客户绑定、产能位置 |
| 认证周期 | design-in、qualification、可靠性测试、量产导入周期 |
| 财务传导 | 如何转化为收入、毛利、订单、capex、估值重估 |
| 证据等级 | 事实、推断、假设 |

## 最小瓶颈节点标准

一个节点满足以下任意条件，就必须单独拆出：

- 独立限制产能或交付节奏。
- 独立影响良率、可靠性、热性能、成本或返工率。
- 替代供应商少，导入或认证周期长。
- 客户不能轻易更换，存在 design-in 或 qualification 壁垒。
- 价格、交期、订单或 capex 已经出现可验证变化。
- 能明确传导到某些公司的收入、毛利率或订单。

## 常见行业下钻示例

| 产业 | 第一层模块 | 第二层下钻示例 |
|---|---|---|
| AI 算力 | GPU / HBM / 先进封装 / 电力 / 液冷 / 光互联 | HBM: DRAM die、TSV、micro-bump、MR-MUF、EMC、burn-in；封装: CoWoS、interposer、ABF、underfill、molding、warpage、void inspection |
| 数据中心电力 | 电网接入、变压器、UPS、PDU、储能 | 取向硅钢、铜线、绝缘材料、开关柜、认证、交付周期 |
| 光通信 | 光模块、光芯片、硅光、连接器、光纤 | EML、CW laser、DSP/LPO、TIA/driver、PIC、FAU、burn-in、客户认证 |
| 液冷 | CDU、冷板、快接头、泵阀、冷却液 | 泄漏检测、可靠性测试、材料兼容性、运维标准、客户 qualification |
| 新能源车 | 电池、电驱、电控、热管理、充电 | 正负极材料、隔膜、电解液、SiC、IGBT、BMS、热泵、快充模块 |
| 机器人 | 执行器、减速器、传感器、控制器、软件 | 谐波减速器、滚柱丝杠、力矩传感器、伺服驱动、边缘算力、数据闭环 |

## 结论分类

| 分类 | 标准 |
|---|---|
| 真瓶颈 | 需求非线性增长，供给扩张慢，替代少，有价格/订单/交期/良率证据 |
| 高景气节点 | 需求强，但供给可较快扩张或竞争者多 |
| 待验证节点 | 逻辑成立，但缺少产能、订单、价格、良率或客户认证证据 |
| 伪瓶颈 | 只是热门叙事，缺少供给约束和财务传导 |

## 反证条件

每个关键结论都要写反证条件：

- 产能扩张快于预期。
- ASP 或交期回落。
- 替代技术路线成熟。
- 客户认证失败或订单延后。
- 库存上升、利用率下降。
- 毛利率没有随短缺改善。
- 关键公司披露与产业链推断矛盾。
