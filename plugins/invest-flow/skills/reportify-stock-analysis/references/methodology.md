# 个股综合分析方法论

## 1) 总体框架

采用“事实层 -> 解释层 -> 决策层”三层结构：

1. 事实层：公司信息、财务数据、股价与技术指标、区域表现、事件进展。
2. 解释层：从业务、竞争、转型、财务四类风险解释数据变化与趋势。
3. 决策层：给出估值锚、情景判断、投资建议与风险提示。

## 2) 八段式分析骨架

1. 公司概况：公司身份、业务边界、战略方向。
2. 财务表现：季度 + 全年，按收入/利润/现金流拆分。
3. 市场表现与技术分析：估值水平 + 动能状态。
4. 业务进展与战略转型：新业务、产能、技术路线、资本动作。
5. 区域市场表现：核心区域分拆（中国/北美/欧洲）。
6. 风险因素：经营、竞争、转型、财务四维。
7. 投资建议与估值：外部机构观点 + 自身估值假设。
8. 综合结论：优势/挑战/操作建议/风险提示。

## 3) 核心分析方法

### A. 财务诊断

- 横向：同比、环比、分业务增速。
- 纵向：收入 -> 毛利率 -> 净利润 -> 现金流 -> 资本开支。
- 目标：判断“增长质量”而不只看增速。

### B. 估值与预期匹配

- 用 P/E、P/B、DCF 假设（WACC、永续增长）建立估值锚。
- 对比“当前估值”与“未来兑现能力”。
- 输出“估值是否透支”的定性结论。

### C. 业务转型可行性评估

- 新业务按“进度、规模、时间表、资本需求”四要素评估。
- 将转型收益与执行风险同时纳入结论。

### D. 风险分层

- 经营风险：销量、利润率、品牌事件。
- 竞争风险：市场份额、产品替代、技术追赶。
- 转型风险：技术落地不确定性、CAPEX 压力、供应链约束。
- 财务风险：高估值、利润下行、现金流承压。

## 4) 输出规范

- 结论必须包含：
  - 核心观点（1 句话）
  - 建议动作（持有/增持/减持/观望）
  - 触发条件（看多）
  - 失效条件（看错）
  - 复核时间（何时重评）
- 数据必须标注时间点与来源。
- 同一指标若出现多个口径，必须标注口径差异。

## 5) 质量控制清单

1. 日期一致：分析日期、行情日期、财报期是否匹配。
2. 数值一致：文内关键数字（如当前股价）前后一致。
3. 口径一致：GAAP/Non-GAAP、TTM/Forward 不混用。
4. 逻辑一致：结论风险等级与正文证据匹配。
5. 引用可追溯：每个核心结论可回溯到至少一个来源。
