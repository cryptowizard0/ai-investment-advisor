# chain-alpha-industry-analysis 方法论

## 1. 行业是什么

先把用户给定的大主题落到可分析的细分行业，不允许直接从主题叙事跳到错位环节。

### 白话解释（先讲人话，不得跳过）

在填六字段表之前，必须先用面向非行业读者的白话回答"这个东西到底是什么"。禁止用行业黑话解释行业黑话（如用"光电共封装"解释 CPO 而不说清它是把什么和什么封装在一起、为了解决什么问题）。固定回答四个问题：

| 问题 | 要求 |
|---|---|
| 它是什么 | 一句话定义 + 一段白话展开：这是个什么产品 / 技术 / 服务，物理上长什么样、装在哪、做什么用 |
| 它替代 / 对比什么 | 现在市场上用的是什么方案，它和现有方案的差别在哪（性能 / 成本 / 功耗 / 效率） |
| 为什么现在需要它 | 什么变化让旧方案不够用了，为什么是现在而不是五年前 |
| 在系统中的位置 | 它在整机 / 数据中心 / 车 / 产线等最终系统里处于哪个位置，占系统成本大概什么量级 |

读者测试：一个不懂该行业的读者读完这一段，应能向别人复述"这个行业卖什么、替代什么、为什么现在火"。做不到就重写，不得进入六字段表。

### 六字段表

每个主题必须回答六个字段：

| 字段 | 说明 |
|---|---|
| 细分行业 | 主题对应的具体行业边界；若有多个候选行业，列出并说明本次主边界 |
| 解决的问题 | 该行业为客户解决什么效率、成本、性能、合规或供给问题 |
| 商业逻辑 | 行业如何收费、如何扩张、利润池来自哪里 |
| 终端客户 | 真实付费方或预算负责人，如 hyperscaler、车企、工业客户、政府、运营商 |
| 预算来源 | capex / opex / BOM 成本转移 / 政策资金 / 替换周期，标注是否已落地 |
| 价值链盈利方式 | 价值如何在上游材料、中游制造、下游系统或生态服务间分配 |

行业定义必须区分事实、推断、假设。若只能证明“主题热”，但无法说明客户、预算和商业逻辑，后续增长判断必须降置信度。

## 2. 增长快吗

增长初筛回答四个问题：增速快不快、现在处于哪个产业周期阶段、为什么快（以及为何能维持高位）、能持续多久。

### 增速快不快
- 行业 / 环节收入增速 >20% 是进入产业链全景和错位识别的增长初筛硬门槛；低于 20% 或证据缺失时，不进入后续环节。
- 收入增速不能替代利润增速。进入第二步的硬门槛仍是代表公司或可投标的未来 1-2 年可持续利润增速 ≥20%，≥30% 优先。
- 增速口径必须说明是行业收入、出货量、订单、capex、segment revenue、净利润、EPS 还是 operating profit。

### 产业周期定位（现在处于哪个阶段）

把行业放到四阶段产业周期上定位，输出各阶段的预测时间表并标注当前节点。

| 阶段 | 典型特征 |
|---|---|
| 技术验证期 | 出货量接近零，以样品 / demo / 标准制定为主，收入可忽略 |
| 商用起步期 | 头部厂商商业化发布，首批量产订单出现，收入从零起步 |
| 规模上量期 | S 曲线开始向上，出货量 / 收入加速，产能成为约束 |
| 大规模渗透期 | 渗透率走向主流，市场空间达到目标量级，增速逐步回落 |

要求：
- 每个阶段给出预测时间（年份或年份区间），用 `← 当前节点` 标注现在所处阶段；时间为推断时标注证据等级。示例格式（数字仅演示）：

```text
2021-2024   技术验证期    出货量接近零
2025        商用起步期    NVIDIA、Marvell 商业化发布
2026-2027   规模上量期    ← 当前节点，S 曲线开始向上
2028-2030   大规模渗透期  市场空间 100 亿美元量级
```

- 每个阶段至少绑定一个可验证的里程碑（产品发布、量产公告、出货量 / 渗透率数据、市场空间测算），标注来源与日期。
- 周期定位与增长门槛联动：技术验证期通常增速证据缺失，增长门槛难以通过，只能进观察池；规模上量期是 chain-alpha 的最佳射程；大规模渗透期后段增速自然回落，持续性判断必须从严。

### 增速为什么快
- 预算落地：capex 指引、招标、订单、客户扩产、政策资金或 BOM 成本转移。
- 渗透率提升：从低渗透到高渗透，说明当前渗透率和提升路径。
- 单位用量提升：终端每增长 1 单位，该环节用量是否线性或非线性增加。
- 替换周期缩短：技术升级、法规、可靠性或效率要求导致换代。
- 技术升级：新规格、新工艺、新标准让旧供给失效或用量提升。

### 增速为何能维持高位（门槛通过时必做）

增长门槛通过不等于分析结束：必须逐驱动解释增速为什么能维持在高位，而不是只给一个总增速数字。

- 对每个成立的驱动，给出可见性证据：订单 / backlog 覆盖几个季度、capex 指引覆盖几年、当前渗透率距天花板还有多远、单位用量路线图（下一代产品用量是升是降）、替换周期节奏。
- 指出哪个驱动会最先衰减，以及增速下台阶的最早触发信号（如某大客户 capex 见顶、渗透率过 50%、下一代技术方案分流）。
- 多个驱动叠加时说明主次：主驱动断了增速是否还能站住 20% 以上。

### 增速能持续多久
- 默认判断窗口为 6-24 个月；用户另有指定时按用户窗口。
- 持续性必须结合预算周期、订单覆盖、客户扩产节奏、供给响应时钟和替代方案。
- 若增长只来自一次性补贴、低基数、并表或价格短期波动，不能按高持续性处理。

### 行业增长门槛（一票否决）

只有同时满足以下三项，才继续进入产业链全景和错位识别：

| 门槛 | 通过标准 | 失败处理 |
|---|---|---|
| 增速 | 行业 / 关键环节收入增速 >20%，且有公开证据或可追溯推断 | 标记"行业增长门槛失败：增速不足 / 证据缺失" |
| 原因 | 至少一个增长驱动成立：预算落地、渗透率提升、单位用量提升、替换周期缩短、capex、政策或技术升级 | 标记"行业增长门槛失败：增长原因不清" |
| 持续性 | 增长窗口至少 6 个月，优选 6-24 个月；一次性补贴、低基数、并表或短期价格波动不算 | 标记"行业增长门槛失败：持续性不足" |

门槛失败时，报告只输出行业定义、增长判断、失败原因和重新触发条件，不再输出产业链全景、错位环节卡片或第二步交接。若用户明确要求保留全景作为学习材料，必须标注"非 chain-alpha 放行结果，不进入后续环节"。

## 3. 产业链全景列表

从终端需求倒推，按四段组织：上游（材料/设备/部件）、中游（制造/集成）、下游（产品/服务/终端客户）、生态支撑（软件/标准/运维/基础设施）。

每个环节必须填齐七个字段：

| 字段 | 说明 |
|---|---|
| 环节名称 | 可独立影响产能、成本、交期或利润分配的最小一级颗粒度 |
| 作用 | 该环节在链条中解决什么问题 |
| 需求来源 | 需求由哪个下游环节或终端预算驱动 |
| 供给弹性 | 高（6 个月内可扩）/ 中（6-18 个月）/ 低（>18 个月或受技术/认证限制） |
| 代表公司 | 全球代表公司，必须含中国大陆及日韩台欧供应商（如适用） |
| 价值池大小 | 该环节年收入规模量级估计，标注来源或"推断" |
| 利润增速线索 | 代表公司或可投标的未来 1-2 年净利润 / operating profit / EPS 增速线索；<20% 不放行，20-30% 低档通过，≥30% 优先 |

完整性检查：沿着"终端产品由哪些子系统构成、每个子系统需要什么材料/设备/工艺"自问，直到无新环节出现。

## 4. 供需错位判断

错位 = 需求增量大 + 供给跟不上 + 能落到利润增速。需求、供给、利润三侧都要有证据。

第一性原理：股价长期跟着公司利润走，行业筛选的所有指标最终都要落到"利润增速"。收入增长、订单、价格、交期只是不完整的中间证据，必须继续追问是否能转化为可持续利润增速。收入增速 >20% 是进入本节的增长初筛硬门槛，利润增速 ≥20% 才是进入第二步的放行硬门槛。

### 需求侧（为什么需求增加）
- 增量来源：新应用、渗透率提升、单位用量提升、替换周期缩短，明确属于哪一类。
- 预算来源：谁在花钱，预算是否已落地（资本开支指引、订单、招标）。
- 单位用量弹性：终端每增长 1 单位，该环节用量增长多少；非线性增长（>1 倍）是强信号。

### 供给侧（为什么供给跟不上），至少落实一项并给出证据
- 扩产周期长：新产能从决策到量产 >18 个月（厂房、设备交期、爬坡）。
- 技术壁垒：良率、专利、工艺 know-how 限制新进入者。
- 公司不愿扩产：寡头资本纪律、上一轮过剩记忆、客户不签长约。
- 认证周期：客户验证 6-24 个月，切换供应商成本高。

供给侧证据必须配合 §6 供给响应时钟双向读：证明"当下跟不上"的同一份扩产证据，也在预告"何时赶上来"。

### 利润侧（为什么能带来利润增速）
- 利润口径优先级：净利润 / EPS；周期或转型公司可辅以 operating profit、segment operating income，但必须说明与净利润的差异。
- 增速门槛：未来 1-2 年可持续利润增速最好 ≥30%，最低 ≥20%；低于 20% 的环节不得进入第二步。
- 可持续性证据：至少说明量、价、毛利率、费用率、产能利用率、订单持续性中的两个驱动是否能支撑利润增长，而不是一次性补贴、汇兑、并表或低基数。
- 数据不可得：标注"利润增速证据缺失"，不得用收入增速直接替代；证据缺失的环节只能进入观察池，不能放行到第二步。

### 硬门槛（一票否决）
供给约束实证至少一项：价格上涨、交期拉长、订单积压（backlog 增长）、产能利用率高位。利润增速必须有 ≥20% 的可持续落点。只有逻辑推演、没有任何一项供给实证的环节，标记"高景气，非错位"；有供给实证但利润增速 <20% 或证据缺失的环节，标记"利润弹性不足 / 利润增速待证"。

## 5. 错位强度评分（满分 30）

| 维度 | 5 分标准 | 0 分标准 |
|---|---|---|
| 需求增量确定性 | 预算已落地、多客户验证 | 仅叙事，无预算证据 |
| 单位用量弹性 | 单位用量非线性增长且有数据 | 用量随终端线性甚至下降 |
| 供给约束强度 | 扩产 >18 个月且有技术/认证壁垒叠加 | 6 个月内可扩产 |
| 证据强度 | ≥3 项实证（价格/交期/订单/利用率） | 仅 1 项实证 |
| 错位定价程度（反向） | 市场基本未定价：代表公司近 12 个月涨幅平淡、估值处自身历史中低分位、卖方覆盖/一致预期稀少 | 充分定价：代表公司已大幅跑赢、估值处自身历史高分位、错位已是一致预期或资金拥挤 |
| 利润增速兑现度 | 代表公司或可投标的未来 1-2 年利润增速 ≥30%，且量价/毛利/费用率证据支持可持续 | 利润增速 <20%、主要靠一次性因素，或利润证据缺失 |

错位定价程度是反向维度，防的是周期顶陷阱：供给约束实证（涨价/交期/积压/利用率）恰在周期顶最强，若不问"错位已被定价多少"，会在最危险的时点给出最高分。判分必须落在证据上：取环节内 2-3 家代表公司，看近 12 个月相对基准涨幅、PE/PS 处自身历史什么分位、卖方一致预期是否已把错位写进模型，至少取证一项；全部不可得时该维度记 2 分（中性）并标注"定价程度证据缺失"。

利润增速兑现度判分：≥30% 且连续性证据强给 4-5 分；20-30% 或 ≥30% 但可持续性证据一般给 2-3 分；<20%、一次性利润或证据缺失给 0-1 分，且不得进入第二步。

得分最高的 2-4 个环节进入第二步；其余通过硬门槛的环节一律进入观察池（无论分数）并写明缺什么证据；硬门槛未过的不评分。错位定价程度 0-1 分（充分定价）的环节即使总分靠前，交接给第二步时必须显式标注"定价拥挤"，供第三步估值透支判断使用；利润增速兑现度 0-1 分的环节不得交接给第二步。

## 6. 供给响应时钟（扩产证据双向读）

同一份扩产 / capex 证据必须双向读：它既证明"当下供给跟不上"（扩产周期长 = 短期约束成立），也预告"供给何时赶上来"（错位关闭的时钟已启动）。只读一面，会把周期顶的紧缺误判为持久错位。

错位环节卡片必填四个字段：

| 字段 | 说明 |
|---|---|
| 最近一波扩产公告 | 环节内主要玩家最近一次大额扩产 / 新玩家进入公告的时间与规模 |
| 落地时点 | 已公告新产能的预计投产 / 量产时点（公司指引，或按典型建设周期推断并标注"推断"） |
| 公告→量产典型周期 | 该环节从扩产决策到形成有效产能的典型时长（含认证） |
| 错位预计收窄时点 | 综合判断错位最早何时开始收窄；给不出就标注"无可见供给响应" |

判读规则：
- 已公告产能落地时点距今 ≤12 个月且规模足以覆盖需求缺口 → 供给约束强度最高记 3 分，评分汇总处置栏标注"错位收窄中"。
- 无任何扩产公告，或扩产被资本纪律明确压制 → 供给响应时钟未启动，是错位持续性的加分证据。
- 时钟判断本身区分 事实（公告）/ 推断（典型周期外推）/ 假设，标注来源与日期。
