## 口径与失真检查(待补充)

- **口径一致性**:当前值、历史序列、分位是否同源同口径?(混口径会让分位失效)
- **盈利周期位置**:成分盈利是否处于周期底?若是,整体法 PE 会被动抬高、分位钝化,「高分位 ≠ 单纯贵」。
- **对照口径**:必要时用等权 PE / PB / PS / forward PE 复核(尤其半导体、硬科技等强周期板块)。
