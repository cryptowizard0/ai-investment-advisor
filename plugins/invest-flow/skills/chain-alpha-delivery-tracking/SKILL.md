# chain-alpha 营收兑现追踪

## Web Research Routing

- 当任务需要联网搜索、网页抓取或多页研究，且当前 agent 会话已安装对应 Firecrawl skill 时，优先使用 `firecrawl-search`（发现来源）、`firecrawl-scrape`（单页提取）、`firecrawl-crawl`（站点遍历）或 `firecrawl-deep-research`（多来源深研）。
- Firecrawl skill 不可用或调用失败时，再回退到当前会话提供的 web search / browser 工具。
- 工具优先级不得降低证据标准：仍优先公司公告、监管文件、交易所、IR 等一手来源，并按本 skill 的规则交叉验证。

## Overview

本 skill 是 chain-alpha 工作流的下游跟踪模块，定位为 `chain-alpha-verification` 的下游：对 verification 产出的 `待验证`（以及在监控中的 `通过 / 金池子`）标的做前瞻性"营收兑现"判断。

核心命题：营收兑现 = 现实沿一条验证链往前推进的进度，对比估值已经 price-in 的位置。对 `待验证` 标的，目标业务的成长当前在财报里往往几乎为 0，等显现在财报上时股价常已完成 re-rating，因此用滞后财务指标盯不住。

第一性原理：股价长期跟着公司利润走，跟踪最终必须落到利润增速。目标业务利润增速最好 ≥30%，最低 ≥20%；低于 20% 视为兑现不足或降档压力，除非有已点亮验证链背书的短期一次性扰动解释。

输出兑现度结论 + 升 / 降档建议，回灌 chain-alpha 的档位与仓位。

默认输出目录：`./output/chain-alpha-delivery-tracking/`

## Trigger

- `使用 invest-flow:chain-alpha-delivery-tracking 跟踪 688017`
- 作为 `chain-alpha-verification` 的"跟踪指标 / 升档触发"与 `chain-alpha-pipeline` 的"跟踪计划"被引用调用

非美股不排除；A 股、港股、日股、台股主板标的按各自上市地市场口径处理，历史分位用该股本地市场数据。

## Workflow

先读 `references/methodology.md`（验证链点灯标准与兑现窗口、三引擎口径、格局哨兵、升降档与回灌规则、可选 B 评分细则）与 `references/report-template.md`（兑现追踪卡模板），再按以下步骤执行。全程区分 事实 / 推断 / 假设；关键数字标来源与日期；不得编造数据。

### 1) 验证链点灯
逐级判断当前点亮到哪一级，**逐级点亮、不可跳级**；估值只能按"已点亮的最高级"给。

| 级别 | 闸门 | 性质 |
|---|---|---|
| L1 | 订单 / 定点（AVL、定点函、中标、批量订单公告） | 领先·事件驱动 |
| L2 | 产能 / 供应链（投产、达产、稼动率、量产阶段切换） | 领先·季度 |
| L3 | 下游放量（绑定整机厂实际出货 / 排产上量带动本供应商上台阶） | 半领先·季度 |
| L4 | 入表（分水岭，须同时满足引擎 A 增速达标 ∧ 引擎 B 归因达标 ∧ 占比连续 ≥2 季上升） | 滞后·硬·季度 |
| L5 | 盈利兑现（目标业务毛利率企稳 / 改善、净利与经营性现金流跟上、应收存货质量健康） | 最滞后·硬·季度 |

低级热、高级暗 = 纯预期，不算兑现。

每级点亮须记录**点亮日期**（以可考证的公告 / 财报日期认定；不可考证时以首次纳入追踪日起算）。级间设**兑现窗口**（默认 L1→L2 ≤4 季、L2→L3 ≤4 季、L3→L4 ≤3 季、L4→L5 ≤4 季；可按行业周期在首次追踪卡定制并写明理由，此后不得回溯放宽）。窗口用尽而下一级未点亮 = **超时**，是独立降档钩子；改叙事不能续命，唯一重启条件是该级灯熄后凭新硬证据重新点亮。细则见 `references/methodology.md`。

### 2) 三引擎判定
在 L4 / L5 层做硬兑现确认与防坑：
- **引擎 A 增速**：目标业务收入与净利 YoY（辅以 QoQ 看拐点）、连续达标季数；净利 / operating profit / EPS 增速最低 20%、优选 30%+；"预期"锚三条——① 估值隐含增速（主锚）② 指引隐含 ③ 同环节可比中位数。输出 达标 / 相当 / miss。
- **引擎 B 归因**（质 / 量 / 势，阈值可调不写死）：质 = 增量是否来自经常性目标业务（剔除理财、补贴、汇兑、并表、口径变更等一次性）；量 = 目标业务增量 ÷ 总增量是否主导；势 = 占比是否连续 ≥2 季上升。输出 达标 / 存疑 / 不达标；不达标 = 账面兑现非业务兑现，L4 不点亮。
- **引擎 C 动态估值**（PE / PS 双轨 + Forward PE 预期收益率分解）：早期薄利放量期看 PS / EV·Sales（对应 L4 收入兑现），利润成熟期看 PE / EV·EBIT（对应 L5）；用本期增速外推 forward 估值，比对**该股自身历史分位带**（不看绝对值）。**Forward PE 收紧两口径**：分子(前瞻盈利)只能用验证链已点亮级别背书的兑现盈利、不得用 L1-L2 纯预期反向 justify；分母必须显式假设退出倍数(锚历史中位/中低分位)、不默认倍数不变。决策从"等它跌到便宜"换成**预期收益率分解**（年化回报 ≈ EPS CAGR + 退出倍数变化(de-rating) + 股东回报）——此为**通用方法**，"确定性"不是门槛而是调参旋钮：验证链亮 L4/L5（高确定）则 PE 为主、情景带窄；仅亮 L1-L3（低确定，待验证标的多属此类）则降权 PE、改用 PS 盯收入、加宽情景带、以下行地板为主锚。**周期成长股**(AI 硬件/半导体/光模块等)禁用"永远高估值"叙事，forward 只外推到可见景气周期内，并须叠加**下行情景地板估值**(周期中位盈利 × 历史低分位倍数)。重估开关须被验证链背书；转型期可用 SOTP。输出 进合理带 / 匹配 / 透支 / 重估后重定价合理。
- 引擎 C 所需的「该股自身历史分位带」与分位回落敏感性，可用 `invest-flow:company-valuation-risk` 预生成（TTM PE/PS 双轨同口径）。

### 3) 格局哨兵（标的财报之外的侵蚀信号）
三引擎与灯带全部读标的自身数据；而垄断被侵蚀时，最早的证据出现在竞对与客户的公告里。每期必查四类哨兵，逐项输出 无信号 / 弱信号 / 强信号（证据同样区分 事实 / 推断 / 假设）：
- **S1 竞对扩产**：同环节主要竞对新产能 / 大额 capex / 跨界转产公告。
- **S2 客户二供**：主要客户认证第二供应商、订单转移证据。
- **S3 客户自研**：大客户自研替代 / 垂直整合立项。
- **S4 需求方 capex**：环节主要需求方的资本开支指引变化（下修 = 需求侧坍塌前兆）。

任一**强信号**为独立降档钩子，不得因三引擎读数良好而豁免；**弱信号**不降档，但写入反证条件并列为下期必查项。

### 4) 升降档与 chain-alpha 档位映射（双向对称）
- **升档**（待验证→通过，通过→金池子）：需同时 灯进 L4 ∧ A 达标 ∧ B 达标 ∧ C（进合理带 或 重估被验证链背书）→ 触发 chain-alpha 仓位（"通过"× 0.5；弹性标的再 × 0.5）。
- **降档**（通过→待验证/剔除，待验证→剔除）：触发其一即降——灯熄（丢单 / 指引下修）∨ A 连续 miss ∨ B 恶化（靠非经常性撑）∨ C 因下修或叙事透支重新扩张 ∨ 兑现窗口超时 ∨ 任一格局哨兵强信号。
- **维持**（待验证）：列明"还差哪一项可升档"。
- **回灌 chain-alpha**：更新对应 verification 验证卡的档位 + 仓位上限，产出"本期 vs 上期"变更 delta 与触发项；维持 chain-alpha 既有回撤推断与风险预算法仓位公式不变。

### 5) 输出兑现追踪卡
- 使用 `references/report-template.md`，单标的一张兑现追踪卡（验证链灯带 + 灯位变化与兑现窗口读数、三引擎读数、格局哨兵读数、预期差对账、本期结论与触发项、回灌档位 / 仓位 / delta、反证条件更新与下次复盘时间、数据来源）。
- 保存至 `./output/chain-alpha-delivery-tracking/chain-alpha-delivery-tracking-{TICKER}-{YYYY-MM-DD}.md`；文件已存在时追加 `(1)`, `(2)`，不覆盖。
- 报告必须包含固定作者字段：`InvestmentFlow`。

## Quality Rules

- 中文输出；金融术语可保留 English。
- 逐级点灯不可跳级；估值只能按"已点亮的最高级"给。
- 兑现窗口在首次追踪卡设定后不得回溯放宽；超时即触发降档，不得以新叙事重置时钟（该级灯熄后凭新硬证据重新点亮才可重启窗口，并记录原因）。
- 格局哨兵每期必查；任一强信号为独立降档钩子，不得因三引擎读数良好而豁免；弱信号必须写入反证条件。
- 可选 0-100 兑现度分仅用于观察池内排序，不得凌驾于阶段闸门之上，不能用高分救回未点亮 L4 的标的。
- 估值 PE / PS 双轨；历史分位锚定该股自身历史分位，不看绝对值。
- Forward PE 必须满足：分子用验证链背书的兑现盈利、分母显式假设退出倍数（不默认倍数不变）；用预期收益率分解（EPS CAGR + de-rating + 股东回报）判断，而非绝对便宜。
- 周期成长股禁用"永远高估值"叙事，forward 只外推到可见景气周期内，并须给出下行情景地板估值。
- 重估（换新眼光）必须被验证链背书；L1-L2 热而 L4 暗的重估记为叙事透支（降档钩子），不给新带。
- 严格区分 事实 / 推断 / 假设；关键数字标来源与日期；不得编造数据。
- 报告含固定作者字段 `InvestmentFlow`。
- 输出是研究与跟踪优先级，不是交易指令。
