# chain-alpha-delivery-tracking 方法论

本文件是设计文档 `docs/superpowers/specs/2026-06-18-chain-alpha-delivery-tracking-design.md`（§2–§6）的可执行细则。SKILL.md 保持精简并指向本文件。

体系 = 验证链阶段闸门（骨架）+ 三个判定引擎（增速 / 归因 / 动态估值）+ 升降档与 chain-alpha 档位映射（回灌）。阶段闸门负责诚实判断"兑现到了哪一级"并防跳级、保持双向对称；三引擎在 L4 / L5 层做硬兑现确认与防坑；可选 B 评分仅作观察池排序辅助层。

核心命题：营收兑现 = 现实沿一条验证链往前推进的进度，对比估值已经 price-in 的位置。升档（拓仓）= 现实推进速度 > 预期 且 估值未吃满；降档（证伪）= 某一环卡住 / 指引下修。

## 1. 验证链 5 级阶段闸门

成文硬规则：**逐级点亮、不可跳级；估值只能按"已点亮的最高级"给；低级热、高级暗 = 纯预期，不算兑现。** 估值即便要给新带，也只能给到当前已点亮的最高级别所支撑的程度，不可用更高级别的预期反向支撑当前估值。

| 级别 | 闸门 | 点亮标准（可证伪硬证据） | 不算点亮（伪信号） | 性质 / 频率 |
|---|---|---|---|---|
| L1 | 订单 / 定点 | 进客户合格供应商名录(AVL)、定点函(SOP nomination)、中标 / 框架协议、批量订单公告 | 送样、接洽、战略合作 MOU、媒体传闻 | 领先·事件驱动 |
| L2 | 产能 / 供应链 | 该业务产线投产 / 达产、在建转固、稼动率提升、送样→小批量→量产阶段切换（公告或产业链调研验证） | "规划产能""拟投资""预计量产" | 领先·季度 |
| L3 | 下游放量 | 所绑定整机厂（Optimus / 宇树 / Figure…）实际出货 / 排产上量，带动本供应商出货上台阶 | 整机厂发布会、路线图、目标产量口号 | 半领先·季度 |
| L4 | 入表（分水岭） | 目标业务分部收入显性出现 **且** 增速达标（引擎 A）**且** 归因达标（引擎 B）**且** 占比连续 ≥2 季上升 | 总收入涨但拆不出来 / 靠理财补贴撑 / 占比不升 | 滞后·硬·季度 |
| L5 | 盈利兑现 | 目标业务毛利率企稳或改善、净利与经营性现金流跟上、应收 / 存货质量健康（非靠放账期铺货堆收入） | 增收不增利、利润靠非经常、应收激增 | 最滞后·硬·季度 |

判级要点：
- L1–L3 为领先 / 半领先信号，事件或季度驱动；L4 / L5 为滞后硬信号，按季度确认。
- L4 是分水岭：它本身已内含引擎 A 增速达标 + 引擎 B 归因达标 + 占比连续 ≥2 季上升三项硬条件，缺一不点亮。
- "灯位"应记录当期最高点亮级别，并标注相对上期的灯位变化（前进 / 持平 / 熄灭）。

## 2. 引擎 A — 增速判定

- 指标：目标业务收入 YoY、净利 YoY（辅以 QoQ 看拐点），以及连续达标季数。
- "预期"锚三条：
  1. **估值隐含增速（主锚）** —— 由当前 forward 估值反推市场已 price-in 的增速，作为达标基准。
  2. 指引隐含增速 —— 管理层指引外推（很多 A 股不给量化指引时降权）。
  3. 同环节可比中位数 —— 取 chain-alpha-monopoly-screen / verification 同子环节候选公司中位数，不足 3 家时扩展至同环节全球公司。
- 输出：**达标**（≥ 估值隐含增速）/ **相当**（与隐含锚相当或单季跑赢）/ **miss**（低于隐含锚）。
- 连续 miss 计入降档触发项。

## 3. 引擎 B — 归因判定（质 / 量 / 势）

阈值可调、不写死。判定增量到底是不是"业务兑现"，防止账面收入伪装成业务放量。

- **质**：增量是否来自经常性目标业务？必须剔除理财收益、政府补贴、汇兑损益、并表、会计口径变更等一次性因素，并列出剔除明细。
- **量**：目标业务增量 ÷ 总增量 ≥ 可配阈值（默认判"是否主导"）。**注：50% 仅为举例口径，不固定为某个数字，须按标的 / 场景设定阈值并在卡中注明实际取值。**
- **势**：目标业务收入占比是否连续 ≥2 季上升。
- 输出：**达标 / 存疑 / 不达标**。不达标 = "账面兑现非业务兑现"，**L4 不点亮**。

## 4. 引擎 C — 动态估值判定（PE / PS 双轨 + 历史分位锚 + 重估开关 + SOTP）

**双轨（不只看 PE）：** PS / EV·Sales 与 PE / EV·EBIT 并看。早期 E 太小或失真（净利大幅波动、靠理财）时 PE 无意义，须用 PS 盯收入兑现。

| 轨 | 主看阶段 | 对应链 | 含义 |
|---|---|---|---|
| PS / EV·Sales | 早期、薄利、放量期 | L4 收入兑现 | 收入兑现进度与 price-in 程度 |
| PE / EV·EBIT | 利润成熟期 | L5 盈利兑现 | 利润是否跟上 |

**桥接恒等式 `PS ÷ 净利率 = PE`：**
- forward PS 压缩（收入兑现）但 forward PE 不降 → **增收不增利**，卡 L4 上不去 L5 → 降档 / 透支钩子。
- 两轨同步压缩 → 收入 + 利润双兑现 → 升档强信号。

**① 历史分位锚（不看绝对值）：** 用本期增速外推 forward PS / PE，再比对**该股自身历史 PS / PE 分位带**。历史均值 100x，则 forward 110x 也可能合理；看落在自身历史什么分位，不看绝对高低。各市场分位用该股本地市场数据，不跨市场套用。

**② 重估开关（业务变了换眼光，但重估必须被验证链背书）：**
- 触发：业务发生 regime change（老业务 → 新成长曲线），历史 PE 失效（类比：特斯拉不再按车企、美光脱离存储周期）。
- 准许换"新眼光"取决于验证链：
  - L3 / L4 已亮（新业务真放量入表）→ **重估成立**，切到新 comp / 新框架 / SOTP 分部估值。
  - L1–L2 热但 L4 暗 → **重估未被兑现背书 = 纯叙事拔估值（反身性透支）**，不给新带，反记透支风险（降档钩子）；可借 reflexivity skill 视角辅助判断。

**③ SOTP 工具：** 转型期公司默认可拆分部估值（老业务 × 老倍数 + 新增量 × 成长倍数），避免单一倍数一刀切。

- 输出：forward 估值 **进入合理带 / 匹配 / 透支 / 重估后重定价合理**。

## 5. 升降档规则与 chain-alpha 档位映射（双向对称）

每个跟踪周期（L4 / L5 与引擎按季度；L1–L3 事件驱动）评估"当前最高点亮级别 + 三引擎读数"，给出动作。

```
升档（待验证→通过，通过→金池子）
  需同时：灯进 L4  ∧  A 达标  ∧  B 达标  ∧  C（进合理带 或 重估被验证链背书）
  → 触发 chain-alpha 仓位（"通过"× 0.5；弹性标的再 × 0.5，可与档位折扣叠乘）

降档（通过→待验证 / 剔除，待验证→剔除）
  触发其一即降：
    · 灯熄（丢单 / 指引下修）
    · A 连续 miss
    · B 恶化（靠非经常性撑）
    · C 因下修或叙事透支重新扩张

维持（待验证）
  其余情形：列明"还差哪一项可升档"
  （如"灯到 L3、A 达标，但 L4 未入表 + C 仍透支"）
```

**说明：L4 点亮已内含 A 达标 + B 达标 + 占比连升**，故升档相对"L4 点亮"的增量要求实为 **C（估值进合理带或重估被验证链背书）**；升档条件处显式并列 A / B / C 以防误读，并非重复要求。

**回灌 chain-alpha：**
- 更新对应 chain-alpha-verification 验证卡的档位 + 仓位上限。
- 产出"本期 vs 上期"变更 delta 与触发的具体项。
- 维持 chain-alpha-verification 既有的回撤推断（三情景取最大）与风险预算法仓位公式不变（仓位上限 = 单笔风险预算 ÷ 预估最大回撤；档位与弹性折扣叠乘）。

## 6. 可选 B 评分（观察池排序辅助层）

- 输出 0–100 兑现度分，**仅用于观察池内排序**。
- 不得凌驾于阶段闸门之上：**不能用高分救回未点亮 L4 的标的**，不能用评分掩盖跳级。
- 评分是辅助层，最终升降档结论以阶段闸门 + 三引擎为准。

## 7. 市场口径与数据源

- 可投范围沿用 chain-alpha-verification：美股 / ADR 主板、A 股、港股、日股、台股主板。非美股不自动排除。
- 估值与历史分位比较：A 股比 A 股、日股比日股；历史分位用该股本地市场数据，不跨市场套用估值基准。
- 价格回撤用候选公司本地市场历史价格（沿用 verification 口径）。
- 数据源优先级（高→低）：
  1. 公司公告 / 财报分部 / 电话会 / IR（硬证据，L4 / L5 与引擎 A / B）
  2. 交易所披露
  3. 行业数据 / 产业链调研（L1–L3 领先信号）
  4. market-data-router（PS / PE、历史分位、价格回撤）
- PS / PE 历史分位与价格回撤经 market-data-router 取数；**降级取数时必须降低置信度并在卡中标注**。
- 全程严格区分 **事实 / 推断 / 假设**；关键数字标来源与日期；不得编造数据。
