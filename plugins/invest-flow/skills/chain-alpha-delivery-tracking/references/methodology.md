# chain-alpha-delivery-tracking 方法论

本文件是设计文档 `docs/superpowers/specs/2026-06-18-chain-alpha-delivery-tracking-design.md`（§2–§6）的可执行细则。SKILL.md 保持精简并指向本文件。

体系 = 验证链阶段闸门（骨架，含级间兑现窗口与超时判死）+ 三个判定引擎（增速 / 归因 / 动态估值）+ 格局哨兵（标的财报之外的侵蚀信号）+ 升降档与 chain-alpha 档位映射（回灌）。阶段闸门负责诚实判断"兑现到了哪一级"并防跳级、保持双向对称；三引擎在 L4 / L5 层做硬兑现确认与防坑；哨兵补上"降档触发全是自家信号"的盲区；可选 B 评分仅作观察池排序辅助层。

核心命题：营收兑现 = 现实沿一条验证链往前推进的进度，对比估值已经 price-in 的位置。升档（拓仓）= 现实推进速度 > 预期 且 估值未吃满；降档（证伪）= 某一环卡住 / 指引下修。

## 1. 验证链 5 级阶段闸门

成文硬规则：**逐级点亮、不可跳级；估值只能按"已点亮的最高级"给；低级热、高级暗 = 纯预期，不算兑现。** 估值即便要给新带，也只能给到当前已点亮的最高级别所支撑的程度，不可用更高级别的预期反向支撑当前估值。

| 级别 | 闸门 | 点亮标准（可证伪硬证据） | 不算点亮（伪信号） | 性质 / 频率 |
|---|---|---|---|---|
| L1 | 订单 / 定点 | 进客户合格供应商名录(AVL)、定点函(SOP nomination)、中标 / 框架协议、批量订单公告 | 送样、接洽、战略合作 MOU、媒体传闻 | 领先·事件驱动 |
| L2 | 产能 / 供应链 | 该业务产线投产 / 达产、在建转固、稼动率提升、送样→小批量→量产阶段切换（公告或产业链调研验证） | "规划产能""拟投资""预计量产" | 领先·季度 |
| L3 | 下游放量 | 所绑定整机厂（Optimus / 宇树 / Figure…）实际出货 / 排产上量，带动本供应商出货上台阶 | 整机厂发布会、路线图、目标产量口号 | 半领先·季度 |
| L4 | 入表（分水岭） | 目标业务分部收入显性出现 **且** 增速达标（引擎 A）**且** 归因达标（引擎 B）**且** 占比连续 ≥2 季上升 | 总收入涨但拆不出来 / 靠理财补贴撑 / 占比不升 | 滞后·硬·季度 |
| L5 | 盈利兑现 | 目标业务毛利率企稳或改善、净利与经营性现金流跟上、应收 / 存货质量健康（非靠放账期铺货堆收入） | 增收不增利、利润靠非经常、应收激增 | 最滞后·硬·季度 |

判级要点：
- L1–L3 为领先 / 半领先信号，事件或季度驱动；L4 / L5 为滞后硬信号，按季度确认。
- L4 是分水岭：它本身已内含引擎 A 增速达标 + 引擎 B 归因达标 + 占比连续 ≥2 季上升三项硬条件，缺一不点亮。
- "灯位"应记录当期最高点亮级别，并标注相对上期的灯位变化（前进 / 持平 / 熄灭）。

### 兑现窗口与超时判死

验证链防"假兑现"，兑现窗口防"真格局但永不兑现"的价值陷阱：升档条件是合取（难）、降档是析取（易），但若没有时限，标的可以无限期滞留观察池——证据链每季都"还活着"，却永远差一口气，而跟踪本身有机会成本。

每级点亮必须记录**点亮日期**：以可考证的公告 / 财报 / 交易所披露日期认定；历史点亮无法考证时，以该标的首次纳入本 skill 追踪的日期起算，并在卡中标注"窗口起点 = 首次追踪日"。

| 窗口 | 默认时限 | 依据 |
|---|---|---|
| L1 → L2 | ≤ 4 季 | 定点后产线建设 / 爬坡的常规节奏 |
| L2 → L3 | ≤ 4 季 | 产能就绪后下游放量的常规节奏 |
| L3 → L4 | ≤ 2 季 | 下游真放量则收入入表应快速显现；拖着不入表多为归因问题 |
| L4 → L5 | ≤ 4 季 | 收入入表后毛利 / 现金流跟上的常规节奏 |

规则：
- 窗口可按行业产能建设 / 认证周期在**首次追踪卡**定制（如半导体建厂放宽至 6 季），必须写明理由；**此后不得回溯放宽**。
- 窗口用尽而下一级未点亮 = **超时**，作为独立降档钩子计入 §6 降档触发（通过→待验证，待验证→剔除）。
- **改叙事不能续命**：不得因"新订单故事 / 管理层新口径 / 行业新叙事"重置时钟。唯一重启条件：该级灯本身熄灭后凭新硬证据重新点亮（证据链重启），窗口重新起算并在卡中记录重启原因。
- 超时降档不是永久拉黑：降档后继续跟踪，再次升档按正常升档条件走。

## 2. 引擎 A — 增速判定

- 指标：目标业务收入 YoY、净利 YoY（辅以 QoQ 看拐点），以及连续达标季数。
- "预期"锚三条：
  1. **估值隐含增速（主锚）** —— 由当前 forward 估值反推市场已 price-in 的增速，作为达标基准。
  2. 指引隐含增速 —— 管理层指引外推（很多 A 股不给量化指引时降权）。
  3. 同环节可比中位数 —— 取 chain-alpha-monopoly-screen / verification 同子环节候选公司中位数，不足 3 家时扩展至同环节全球公司。
- 输出：**达标**（≥ 估值隐含增速）/ **相当**（与隐含锚相当或单季跑赢）/ **miss**（低于隐含锚）。
- 连续 miss 计入降档触发项。

## 3. 引擎 B — 归因判定（质 / 量 / 势）

阈值可调、不写死。判定增量到底是不是"业务兑现"，防止账面收入伪装成业务放量。

- **质**：增量是否来自经常性目标业务？必须剔除理财收益、政府补贴、汇兑损益、并表、会计口径变更等一次性因素，并列出剔除明细。
- **量**：目标业务增量 ÷ 总增量 ≥ 可配阈值（默认判"是否主导"）。**注：50% 仅为举例口径，不固定为某个数字，须按标的 / 场景设定阈值并在卡中注明实际取值。**
- **势**：目标业务收入占比是否连续 ≥2 季上升。
- 输出：**达标 / 存疑 / 不达标**。不达标 = "账面兑现非业务兑现"，**L4 不点亮**。

## 4. 引擎 C — 动态估值判定（PE / PS 双轨 + 历史分位锚 + 重估开关 + Forward PE 预期收益率分解 + SOTP）

**双轨（不只看 PE）：** PS / EV·Sales 与 PE / EV·EBIT 并看。早期 E 太小或失真（净利大幅波动、靠理财）时 PE 无意义，须用 PS 盯收入兑现。

| 轨 | 主看阶段 | 对应链 | 含义 |
|---|---|---|---|
| PS / EV·Sales | 早期、薄利、放量期 | L4 收入兑现 | 收入兑现进度与 price-in 程度 |
| PE / EV·EBIT | 利润成熟期 | L5 盈利兑现 | 利润是否跟上 |

**桥接恒等式 `PS ÷ 净利率 = PE`：**
- forward PS 压缩（收入兑现）但 forward PE 不降 → **增收不增利**，卡 L4 上不去 L5 → 降档 / 透支钩子。
- 两轨同步压缩 → 收入 + 利润双兑现 → 升档强信号。

**① 历史分位锚（不看绝对值）：** 用本期增速外推 forward PS / PE，再比对**该股自身历史 PS / PE 分位带**。历史均值 100x，则 forward 110x 也可能合理；看落在自身历史什么分位，不看绝对高低。各市场分位用该股本地市场数据，不跨市场套用。

**② 重估开关（业务变了换眼光，但重估必须被验证链背书）：**
- 触发：业务发生 regime change（老业务 → 新成长曲线），历史 PE 失效（类比：特斯拉不再按车企、美光脱离存储周期）。
- 准许换"新眼光"取决于验证链：
  - L3 / L4 已亮（新业务真放量入表）→ **重估成立**，切到新 comp / 新框架 / SOTP 分部估值。
  - L1–L2 热但 L4 暗 → **重估未被兑现背书 = 纯叙事拔估值（反身性透支）**，不给新带，反记透支风险（降档钩子）；可借 reflexivity skill 视角辅助判断。

**③ SOTP 工具：** 转型期公司默认可拆分部估值（老业务 × 老倍数 + 新增量 × 成长倍数），避免单一倍数一刀切。

**④ Forward 估值口径与预期收益率分解（通用方法；"确定性"只调参数、不设门槛）：**

> 适用范围澄清：前瞻估值 + 预期收益率分解是**对所有标的通用**的——价值股、周期股、低增长股同样适用，决策都该看"预期收益率与 R/R"而非"绝对便不便宜"。**标的的"确定性 / 成长性"不是能否用本方法的门槛，而只是调节输入参数的旋钮**，且这个旋钮就是验证链点亮级别：
> - **确定性高（验证链已亮 L4 / L5）** → forward E 可信，情景带可收窄，PE 轨为主，可锚历史中位偏上倍数。
> - **确定性低（仅亮 L1–L3，本 skill「待验证」标的多属此类）** → forward E 不可信，**必须降权 PE、改用 PS / EV·Sales 盯收入兑现、加宽情景带、抬高安全边际、以下行地板估值为主锚**，而不是给一个单点 forward PE 就当便宜。
> 换言之：本 skill 跟踪的「待验证」标的天然不是"高确定性"，所以越是这类标的，越要用情景区间 + 地板，而非线性外推的乐观单点。

trailing PE 对高成长标的几乎永远显得"贵"，正确锚是 forward 估值；但 forward PE 不是"把当前 PE 套上未来盈利"那么简单，必须收紧两个口径，否则会把"线性外推的乐观"伪装成"便宜"。

- **口径 1 —— 分子(前瞻盈利)必须被验证链背书。** forward E 只能用"已点亮的最高级别所支撑的兑现盈利"外推（沿用本文档 §1 硬规则），**不得用 L1–L2 的纯预期盈利反向 justify 今天的估值**。L4 暗而拿三年后高增长摊薄 PE = 叙事透支（降档钩子），与重估开关同源。
- **口径 2 —— 必须显式假设一个退出倍数，不能默认"倍数不变"。** 这是 forward PE 最常被忽略的杀手：盈利涨而市场给的倍数被杀（de-rating），照样亏钱。退出倍数应锚定该股**自身历史中位 / 中低分位**（§4①），而非当前高分位。

**预期收益率分解（把"贵不贵"换成"预期收益率合不合理" = 买方语言）：**

```
未来 N 年年化回报 ≈ 盈利复合增速(EPS CAGR)
                  + 退出倍数变化(Δmultiple，de-rating 通常为负)
                  + 股东回报(分红/回购，成长股常≈0)
```

- 决策口径从"等它跌到便宜" → "判断当前价对应的预期收益率与风险收益比是否合理、何时入场 R/R 最佳"。
- de-rating 项必须显式给值：若"盈利翻倍但倍数从 60x→30x"，则价格回报≈0——这类情形 forward PE 看着降了，预期收益率却不达标，记 **透支 / R·R 不佳**，不给升档。
- 与桥接恒等式联动：forward PS 与 forward PE 同步压缩 = 量价双兑现（回报来自 EPS 而非杀估值），是高质量升档信号。

**⑤ 周期成长 vs 永续成长约束（反"永远不会便宜"陷阱）：**

forward PE 外推年限受 regime 约束，先给标的定性：

| 类型 | 特征 | forward 处理 |
|---|---|---|
| 周期成长股 | 有产能-价格周期、客户集中、ASP 年降（AI 硬件 / 半导体 / 面板 / 光模块等） | 只外推到"可见景气周期内"（通常 1–2 年 / 到下一个产能-价格拐点）；**禁用"永远高估值"叙事** |
| 永续复利成长股 | 弱周期、需求长坡厚雪、定价权稳 | 可给更长外推年限与更高稳态倍数 |

- 周期成长股**必须叠加"下行情景 forward PE"**：分子用周期中位盈利（毛利回到中枢、量价回落），分母用历史**低**分位倍数，得出"周期反转时的地板估值"。只有能接受地板情景的风险收益比，才算"真便宜"。
- 该约束与重估开关方向对称：重估开关防"向上的叙事拔估值"，周期约束防"向上的线性外推永续成长"。两者都要求 forward 估值不脱离验证链与该股自身周期史。

- 输出：forward 估值 **进入合理带 / 匹配 / 透支 / 重估后重定价合理**；同时给出 **基准情景 forward PE / PS、退出倍数假设、预期收益率分解、(周期成长股)下行情景地板估值** 四项读数。

## 5. 格局哨兵（标的财报之外的格局侵蚀信号）

设计原则：三引擎与灯带全部读标的自身数据，而垄断被侵蚀时，最早的证据出现在**别人家**的公告里——竞对的产能公告、客户的二供认证、客户的自研立项、需求方的 capex 指引。哨兵是领先信号，引擎是滞后信号；等引擎恶化再降档就晚了。

| 哨兵 | 监测内容 | 弱信号（列观察） | 强信号（降档钩子） |
|---|---|---|---|
| S1 竞对扩产 | 同环节主要竞对新产能 / 大额 capex / 跨界玩家转产公告 | 有扩产公告但规模小或落地 >18 个月 | 公告产能规模足以改变环节供需或 CR3 格局 |
| S2 客户二供 | 主要客户认证第二供应商 / 订单转移 | 客户表达二供意向、送样测试传闻 | 二供通过认证并获批量订单（公告或供应链证实） |
| S3 客户自研 | 大客户自研替代 / 垂直整合 | 招聘 / 专利 / 实验室级自研迹象 | 客户官宣自研并给出量产时间表，或已小批量替代 |
| S4 需求方 capex | 环节主要需求方（top 需求客户群）的资本开支指引 | 单一需求方下修但总盘稳 | 头部需求方集体下修 capex 或明确砍单 |

规则：
- 每个跟踪周期四项哨兵**必查**，逐项输出 无信号 / 弱信号 / 强信号，并附证据（事实 / 推断 / 假设 + 来源 + 日期）；查无信号也要写"本期未发现，检索范围：…"，不得留空。
- **任一强信号 = 独立降档钩子**（计入 §6 降档触发），不得因三引擎读数良好而豁免。
- 弱信号不降档，但必须写入反证条件并列为下期必查项；连续 2 期弱信号且方向恶化，按强信号处理。
- 与 verification 负分项的关系：verification 的"客户自研 / 二供动作 -5"是打分时点的静态检查，哨兵是逐期动态监测；哨兵结论回灌 verification 验证卡的负分项与反证条件。

## 6. 升降档规则与 chain-alpha 档位映射（双向对称）

每个跟踪周期（L4 / L5 与引擎按季度；L1–L3 事件驱动）评估"当前最高点亮级别 + 三引擎读数"，给出动作。

```
升档（待验证→通过，通过→金池子）
  需同时：灯进 L4  ∧  A 达标  ∧  B 达标  ∧  C（进合理带 或 重估被验证链背书）
  → 触发 chain-alpha 仓位（"通过"× 0.5；弹性标的再 × 0.5，可与档位折扣叠乘）

降档（通过→待验证 / 剔除，待验证→剔除）
  触发其一即降：
    · 灯熄（丢单 / 指引下修）
    · A 连续 miss
    · B 恶化（靠非经常性撑）
    · C 因下修或叙事透支重新扩张
    · 兑现窗口超时（下一级未在窗口内点亮，见 §1）
    · 任一格局哨兵强信号（见 §5）

维持（待验证）
  其余情形：列明"还差哪一项可升档"
  （如"灯到 L3、A 达标，但 L4 未入表 + C 仍透支"）
```

**说明：L4 点亮已内含 A 达标 + B 达标 + 占比连升**，故升档相对"L4 点亮"的增量要求实为 **C（估值进合理带或重估被验证链背书）**；升档条件处显式并列 A / B / C 以防误读，并非重复要求。

**回灌 chain-alpha：**
- 更新对应 chain-alpha-verification 验证卡的档位 + 仓位上限。
- 产出"本期 vs 上期"变更 delta 与触发的具体项。
- 维持 chain-alpha-verification 既有的回撤推断（三情景取最大）与风险预算法仓位公式不变（仓位上限 = 单笔风险预算 ÷ 预估最大回撤；档位与弹性折扣叠乘）。

## 7. 可选 B 评分（观察池排序辅助层）

- 输出 0–100 兑现度分，**仅用于观察池内排序**。
- 不得凌驾于阶段闸门之上：**不能用高分救回未点亮 L4 的标的**，不能用评分掩盖跳级。
- 评分是辅助层，最终升降档结论以阶段闸门 + 三引擎为准。

## 8. 市场口径与数据源

- 可投范围沿用 chain-alpha-verification：美股 / ADR 主板、A 股、港股、日股、台股主板。非美股不自动排除。
- 估值与历史分位比较：A 股比 A 股、日股比日股；历史分位用该股本地市场数据，不跨市场套用估值基准。
- 价格回撤用候选公司本地市场历史价格（沿用 verification 口径）。
- 数据源优先级（高→低）：
  1. 公司公告 / 财报分部 / 电话会 / IR（硬证据，L4 / L5 与引擎 A / B）
  2. 交易所披露
  3. 行业数据 / 产业链调研（L1–L3 领先信号）
  4. market-data-router（PS / PE、历史分位、价格回撤）
- 格局哨兵证据（竞对 / 客户 / 需求方公告与指引）按同一优先级取证：公告与财报 > 交易所披露 > 行业数据 / 产业链调研 > 媒体报道；媒体报道最多只够弱信号，不足以支撑强信号。
- PS / PE 历史分位与价格回撤经 market-data-router 取数；**降级取数时必须降低置信度并在卡中标注**。
- 全程严格区分 **事实 / 推断 / 假设**；关键数字标来源与日期；不得编造数据。
