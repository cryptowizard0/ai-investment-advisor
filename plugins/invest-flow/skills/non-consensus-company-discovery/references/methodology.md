# 非共识公司发现方法论

## 核心定义

高潜力非共识公司不是没人知道的公司，而是市场已经看到表面事实，却低估这个事实未来会演化成多大的利润、现金流或战略地位的公司。

分析必须回答五个问题：

| 问题 | 输出要求 |
|---|---|
| 市场共识是什么 | 写成一句明确判断 |
| 市场为什么这样定价 | 估值、担忧、旧分类或短期问题 |
| 市场忽略了什么变量 | 必须是可验证变量 |
| 变量如何转化为业绩 | 收入、毛利率、费用率、现金流或 ROIC 路径 |
| 何时重新定价 | 6-24 个月催化剂和验证指标 |

## 五类非共识机会

### 1. 被错误分类的公司

市场把公司当作 A 类资产定价，但公司正在变成 B 类资产。重估来自估值体系变化。

| 市场认为它是 | 实际可能变成 |
|---|---|
| 硬件公司 | 平台公司 |
| 周期公司 | 结构性成长公司 |
| 外包制造商 | 核心基础设施公司 |
| 工具软件 | 入口级平台 |
| 成本中心 | 利润放大器 |

验证重点：
- 收入结构是否从一次性销售转向订阅、平台、服务或高复购。
- 客户是否把它从可替代供应商提升为战略供应商。
- 毛利率、净留存、backlog 或 RPO 是否支持新分类。

### 2. 当前利润弱但未来利润杠杆强

市场盯当前利润表，但高潜力公司可能处于投入期。关键不是现在是否赚钱，而是收入增长 100% 时，成本是否只增长 30%-50%。

验证重点：
- 毛利率是否提升。
- 销售费用率是否下降。
- 研发费用率是否稳定或下降。
- 经营现金流和 FCF 是否改善。
- 单位经济模型是否转正。

### 3. 处在产业链瓶颈位置

重点不是故事最大，而是谁是增长无法绕开的瓶颈。

| 问题 | 目的 |
|---|---|
| 下游需求增长 10 倍，哪个环节最容易短缺 | 找瓶颈 |
| 这个环节扩产周期多长 | 判断供给弹性 |
| 有多少公司能做 | 判断竞争格局 |
| 客户换供应商难不难 | 判断护城河 |
| 价格上涨能否传导 | 判断利润弹性 |

典型瓶颈包括光模块、HBM、先进封装、特种材料、电力设备、液冷、网络交换芯片、数据中心供电、工业软件和安全合规工具。

### 4. 技术路线被低估

技术路线一旦成立，公司会从边缘角色变成核心角色。

三层验证：
- 技术是否解决真实问题：成本、性能、效率、供给约束或新经济性。
- 商业化是否开始：试点、订单、大客户验证、毛利率改善、产能扩张、管理层 capex。
- 市场是否仍未反应：技术验证开始，但财务报表未完全体现。

### 5. 被短期问题掩盖的长期资产

市场可能因短期问题过度惩罚公司，但客户关系、技术壁垒、数据壁垒、渠道、品牌、生态位、供应链控制力、定价权或稀缺牌照未受损。

判断重点：
- 短期问题是周期性噪音，还是结构性衰退。
- 核心资产是否仍在增强。
- 估值压缩是否给出足够安全边际。
- 是否有明确复苏或重估催化剂。

## 三层漏斗工作流

### 第一层：主题筛选

选择未来 3-5 年确定性较强的大趋势，例如 AI 算力、数据中心电力、先进封装、光通信、存储、机器人、工业自动化、网络安全、军工科技、能源基础设施、医疗设备和金融科技基础设施。

目标：形成 20-50 家候选公司。

### 第二层：产业链筛选

画产业链并寻找：
- 最稀缺环节。
- 扩产最慢环节。
- 毛利率最可能上升环节。
- 客户迁移成本最高环节。
- 技术壁垒最高环节。
- 未来可能从成本项变成战略项的环节。

目标：缩小到 5-10 家。

### 第三层：公司验证

对每家公司形成一页卡片：

```text
公司名称：
市场共识：
我的非共识观点：
核心变量：
财务验证指标：
未来 3 个催化剂：
主要风险：
反证条件：
合理估值区间：
仓位计划：
```

目标：只保留 1-3 个真正值得跟踪的标的。

## 100 分评分模型

| 模块 | 权重 | 高分标准 |
|---|---:|---|
| 趋势强度 | 15 | 大趋势、长周期、需求可持续 |
| 产业链瓶颈位置 | 20 | 瓶颈、稀缺、核心、供给弹性低 |
| 利润弹性/财务拐点 | 20 | 收入增长带来利润率和现金流明显改善 |
| 市场误解/共识盲区 | 20 | 市场仍按旧逻辑、旧分类或线性外推定价 |
| 催化剂确定性 | 15 | 未来 6-24 个月有明确验证点 |
| 估值拥挤度/安全边际 | 10 | 估值未充分反映重估逻辑，拥挤度低 |

评分原则：
- 每个模块必须写证据和扣分理由。
- 估值拥挤度反向打分：越拥挤越低，越有安全边际越高。
- 缺少关键证据时不得给满分；应标记数据缺口。

分类阈值：

| 总分 | 结论 |
|---:|---|
| >=80 | 重点跟踪 |
| 70-79 | 深度研究 |
| 60-69 | 观察池 |
| <60 | 剔除，除非出现新的强催化剂 |

## 财务拐点验证

收入端：
- 增速是否重新加速。
- 大客户订单是否增长。
- 新产品收入占比是否提升。
- 海外收入是否放量。
- backlog 或 RPO 是否增长。

利润端：
- 毛利率是否提升。
- 营业利润率是否改善。
- 费用率是否下降。
- 经营现金流是否转正。
- FCF 是否改善。
- 单位经济模型是否变好。

资产负债表：
- 现金是否足够。
- 债务压力是否可控。
- 存货是否过高。
- 应收账款是否异常增长。
- 资本开支是否对应未来产能。

优质非共识通常遵循：业务逻辑先改善，财务指标后确认，股价最后重估。

## 催化剂

| 催化剂 | 含义 |
|---|---|
| 新产品放量 | 技术路线开始成立 |
| 大客户订单 | 需求真实 |
| 毛利率提升 | 议价权增强 |
| 业绩超预期 | 迫使市场修正模型 |
| 指引上调 | 管理层确认趋势 |
| 资本开支扩大 | 公司主动下注未来需求 |
| 行业缺货 | 供需矛盾显性化 |
| 竞争对手退出 | 格局改善 |
| 政策变化 | 新市场打开 |

没有催化剂的非共识可能长期便宜。重点跟踪标的必须有 6-24 个月验证点。

## 反证机制

每个 Top 候选必须提前写下可观察的反证条件。常见反证信号：
- 收入没有按预期放量。
- 毛利率继续下降。
- 新产品迟迟没有客户。
- 管理层反复降低指引。
- 竞争对手快速追上。
- 客户开始自研替代。
- 应收账款异常增长。
- 存货大幅增加。
- 现金流恶化。
- 估值靠故事维持，财务没有验证。

非共识不是越跌越买。非共识必须有可验证假设。

## 常见陷阱

| 陷阱 | 避免方式 |
|---|---|
| 把冷门误认为非共识 | 必须同时有低关注、差异化认知和未来验证 |
| 把低估值误认为机会 | 检查主业衰退、技术替代、管理层、现金流和负债 |
| 只看故事不看财务路径 | 明确收入、毛利率、客户、竞争和财报体现时间 |
| 过早买入 | 等财务拐点、估值压缩、大客户确认或技术验证 |

## 最简单判断标准

一家公司是否可能是高潜力非共识公司，看五句话能否成立：

```text
1. 它处在一个未来 3-5 年会明显变大的市场。
2. 它所在的环节不是最显眼的，但可能是最稀缺的。
3. 市场仍然用旧逻辑给它定价。
4. 它的财务指标已经开始出现早期改善。
5. 未来 6-24 个月有明确催化剂能证明市场错了。
```
