# Three-Layer Application Layout

- `apps/web`: frontend layer
- `apps/backend`: backend layer
- `apps/agent`: agent layer
- `apps/build-container.sh`: build the Docker image
- `apps/run-container.sh`: run the Docker container
- `apps/start-entrypoint.sh`: single-container startup entrypoint
- `apps/container-runtime.md`: container build and run notes
